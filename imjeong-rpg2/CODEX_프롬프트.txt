『임시정부 : 새로운 나라를 향해』(제2탄, 폴더 imjeong-rpg2) —
대한민국 임시정부가 새 나라의 헌법과 제도를 세우고 운영한 과정(1919~1948)을
학생이 1인칭 3D 로 걸으며 체험하고, 게임에서 모은 「보훈 포인트」로 마지막에
국가유공자께 (게임 속) 기부하고 감사 편지를 쓰는 보훈 역사 RPG.
플레이 대상은 중학교 1학년이다 (고등학생용 심화 문장도 있다).

1탄 『임시정부 1919-1945』(폴더 imjeong-rpg, 쿼터뷰, 외교·군사)의 후속작이며,
1탄의 인물 고증·건물·텍스처·HUD 디자인(먹·황동·삼베 색)을 그대로 이어받았다.
두 게임은 내용으로 연결되어 있다(1탄 돌아보기·기억 퀴즈·「🔗 1탄에서는」·
1탄 완주 시 2탄 안내 카드). 두 폴더를 같은 부모 폴더 아래에 둔다.

기술: React 19 + TypeScript + three.js + zustand + Vite + Vitest.
외부 3D 모델·텍스처·폰트·효과음 파일 없이 전부 코드로 만든다.
서버·로그인 없음. 기록은 브라우저 localStorage 에만.

현재 상태: 장소 6곳, 퀘스트 25개(사료·APA 출처), 기록 조각 17개,
명패 13개, 생각 노트 6개, 교사용 화면(?teacher), 진행 코드.
타입 검사·테스트 133개·빌드 통과 (1탄 테스트 73개 통과).

■ 절대 어기면 안 되는 규칙 (역사 수업·보훈 교육 자료다)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. 모든 퀘스트에 사료 1개 이상, 각 사료에 APA 출처. 정답 선택지만 historical: true.
   order 퀘스트의 choices 는 정답 순서와 다르게 섞어 적는다(화면이 적힌 순서대로 보여 준다).
2. 일자·판본에 이설이 있으면 caveat 로 밝힌다. 「알려져 있다」와 「사실이다」를 섞지 않는다.
3. 인물의 공과를 미화하지 않는다(이광수의 변절, 이승만 탄핵 등 사실대로).
4. 실존 인물의 얼굴을 재현하지 않는다. 차림은 src/data/figures.ts 의 appearance 에만,
   근거는 appearance.note 에. 힉스필드 삽화도 얼굴을 만들지 않는다.
5. 폭력 장면을 조작하게 하지 않는다.
6. 개인정보를 수집하지 않는다. 로그인·서버 저장·외부 전송을 넣지 않는다.
7. 중학교 1학년이 읽을 수 있는 한국어. 어려운 말은 src/data/glossary.ts 에 풀이.
8. 보훈 포인트와 기부는 게임 속 활동이다. 결제·송금·외부 모금 링크를 절대 넣지 않고,
   「실제 돈이 아닙니다」 안내를 지우지 않는다.
9. 명패(src/data/honorees.ts)는 게임에서 만난 독립유공자만. 친일·논란 인물 제외(테스트).
   훈격은 적지 않는다(학생이 공훈전자사료관에서 찾는 활동).
10. 생각 노트는 채점하지 않는 열린 질문이다. 1948년 선택(이시영 / 김구·김규식),
    국민대표회의(개조파 / 창조파)는 어느 쪽이 옳다고 단정하지 않는다.
11. src/data/prequel.ts 의 1탄 제목은 1탄 src/data/quests.ts 의 title 과 글자까지 같아야 한다.
12. 생성 이미지는 「삽화」이지 「사료」가 아니다. 캡션을 지우지 않는다.

■ 코드 규칙
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- 게임 규칙은 src/engine/ 에 순수 함수로. three.js·React 금지. 새 규칙엔 테스트.
- 3D 는 src/three/FirstPersonRenderer.ts 가 React 밖 루프로 돌린다. 매 프레임 React 를 다시 그리지 않는다.
  3D ↔ UI 연결은 src/GameScreen.tsx 한 곳.
- 맵은 src/data/maps.ts 에서 도면 도구(src/data/plan.ts: room/door/windowRow)로 그린다.
  고친 뒤 npm test 의 「장소」 테스트로 벽에 박힌 가구·못 가는 NPC 를 잡는다.
- 좌표: 1칸=1m, x=동쪽, z=남쪽. 플레이어 yaw 0=북쪽(-z). NPC facing 0=남쪽(+z).
  벽걸이·명패 rot: 0=북벽, π=남벽, π/2=서벽, -π/2=동벽.
- 진행 코드(src/engine/progressCode.ts)는 퀘스트·기록 조각 목록 순서가 비트 순서다.
  퀘스트·조각은 목록 맨 끝에만 추가하거나, VERSION 을 올리고 옛 코드 해석을 남긴다.
- 저장 필드를 더하면 src/engine/save.ts 의 emptySave() 기본값과 loadSave() 병합을 함께 고친다.
- 외부 3D·텍스처·음원 파일을 추가하지 않는다(캔버스·Web Audio 로 만든다).
  예외: 힉스필드 삽화는 public/assets/higgsfield/ 에 넣으면 자동으로 붙는다.
- 주석은 「왜」를 한국어로 적는다.
- 커밋 전 2탄·1탄 모두 npm run check.

[1순위 — 사실 확인]
- 국사편찬위원회 한국사데이터베이스·공훈전자사료관·국가법령정보센터로 대조해
  note·caveat 를 고친다. 특히: 1919.9 임시헌법 제5조 문구, 독립공채 상환 특별조치법(1983),
  이승만 탄핵 의결·면직일, 환국 1·2진 명단, 방순희 1939 의원 선출, 정정화 1990 훈장,
  연표의 1927·1930·1940 일자, 관보 제1호 「대한민국 30년」, 독립신문 창간사 요지.
  확인할 수 없으면 단정하지 말고 caveat 로 남긴다.

[2순위 — 실제 기기 검증과 성능]
- 크롬북·태블릿에서 프레임 확인 → 느리면 그림자 크기·픽셀비·watchPerformance 기준 조정.
- 12fps 이하에서 걸음이 느린 문제(delta 0.08 클램프) 개선.
- 첫 3D 적재 중 「장소를 짓는 중…」 로딩 표시 추가.
- 태블릿 세로·휴대폰 가로 HUD 배치 다듬기.

[3순위 — 게임성·학습]
- 지표(국고·민심·외교 신망·제도·통합)가 결과에 영향을 주도록: 막을 마칠 때 지표로
  「그 시대 정부의 형편」 한 줄 평 (역사 사실을 바꾸지 않는 범위).
- 1948년 남북 협상을 다루는 짧은 장면 또는 기록 조각 (관점 균형 유지).
- 교사 화면: 학급 현황 CSV 내려받기, 생각 노트 활동지 인쇄 레이아웃.

[4순위 — 접근성·코드]
- Tab 으로 가까운 인물 순회, aria-live 보강.
- FirstPersonRenderer.ts(약 1,400줄)를 짓기/입력/루프로 분리.

[배포·에셋 — 선생님 컴퓨터에서]
- Firebase 배포(docs/DEPLOY.md). 2탄 주소를 1탄 .env 의 VITE_SEQUEL_URL 에 넣고 1탄 재배포.
- 힉스필드 MCP 로 삽화 40장 생성: npm run assets:higgsfield -- --json (docs/HIGGSFIELD_MCP.md).

작업을 하나 마칠 때마다 무엇을 바꿨는지, 테스트 결과, 확인하지 못한 것을 짧게 보고하고 커밋한다.
