## 2. 이 게임이 무엇인가

- 1탄 『임시정부 1919-1945』(쿼터뷰, 외교·군사) → 2탄은 같은 사람들이 **나라를 세우고 꾸린 과정**
  (국호·임시헌장·삼권분립·연통제·재정·외교·탄핵과 개헌·건국강령·1948년 헌법·오늘의 헌법 전문)을 **1인칭**으로 걷는다.
- 학생은 「보훈의 전당」(가상)에서 해설사에게 기록 수첩을 받아 시간의 문으로 5개 시대를 건너고, 돌아와
  **보훈 포인트로 명패 13개 앞에서 기부(국화)·감사 편지(봉투)·보훈 다짐**을 남긴다 → 감사 증서 인쇄.
- 대상: **중학교 1학년** (고등학생용 심화 문장도 모든 텍스트에 있음).

## 3. 절대 깨뜨리면 안 되는 규칙

1탄의 규칙을 모두 이어받고(1~7), 2탄에서 더한 것(8~14)이 있습니다.

1. **모든 퀘스트에 사료 1개 이상, 사료마다 APA 출처.** (테스트)
2. **정답 선택지만 `historical: true`.** `order` 퀘스트는 화면이 `choices` 를 적힌 순서대로 보여 주므로
   **choices 를 정답 순서와 다르게 섞어 적는다.** (테스트)
3. **이설이 있으면 `caveat`.** 「이렇게 알려져 있다」와 「사실이다」를 섞지 않는다.
4. **실존 인물의 얼굴을 재현하지 않는다.** 차림은 `src/data/figures.ts` 의 `appearance` 한 곳에서만, 근거는 `note` 에.
   (1탄 인물 사전을 그대로 복사해 왔다. 1탄과 어긋나지 않게 고칠 때는 두 곳을 함께 고친다)
5. **폭력 장면을 조작하게 하지 않는다.** 힉스필드 프롬프트도 마찬가지.
6. **개인정보 수집 금지.** 로그인·서버 저장 없음. 기록은 localStorage(`imjeong-rpg2:*`) 에만.
   편지 「부름말」은 선택이며 실명 금지 안내가 있다. 진행 코드에도 개인정보를 넣지 않는다.
7. **중1이 읽을 수 있는 문장.** 어려운 말은 `src/data/glossary.ts` 에.
8. **보훈 포인트·기부는 게임 속 활동이며 실제 돈이 아니다.** 결제·송금·외부 모금 링크를 절대 넣지 않는다.
   화면마다 이 문구가 있다 — 지우지 않는다.
9. **명패(`src/data/honorees.ts`)에는 게임에서 직접 만난 독립유공자만.** 친일 행적이 있거나 평가가 크게 엇갈리는
   인물(이광수·이승만·이동휘)은 넣지 않는다. (테스트) 예외는 무명 협력자 명패 `unnamed` 하나.
10. **훈격(대한민국장 등)을 게임에 적지 않는다.** 학생이 공훈전자사료관에서 직접 찾는 것이 학습 활동이다.
11. **생각 노트는 채점하지 않는다.** 정답이 있는 것처럼 만들지 않는다. 특히 제3막(개조파·창조파)과
    제5막(1948년 이시영 / 김구·김규식의 선택)은 **어느 쪽이 옳다고 단정하지 않는다.**
12. **1탄 연결 제목 동기화.** `src/data/prequel.ts` 의 「」 안 제목은 1탄 `src/data/quests.ts` 의 `title` 과
    글자 하나까지 같아야 한다. (테스트가 1탄 파일을 읽어 검사)
13. **생성 이미지는 삽화이지 사료가 아니다.** 화면 캡션 「삽화 — 사료가 아닙니다」를 지우지 않는다.
14. **재구성을 밝힌다.** 플레이어·해설사·보훈의 전당은 가상, 청사 방 배치는 재구성 — 각 맵의 `historicalNote`.

### 좌표·방향 약속 (자주 헷갈림)

- 1칸 = 1 m. x 는 동쪽(오른쪽), z 는 남쪽(아래). 도면 문자열의 첫 줄이 북쪽.
- **플레이어 `yaw` 0 = 북쪽(-z)을 본다.** (three.js 카메라 기본) `yawToward(dx, dz)` 사용.
- **NPC `facing` 0 = 남쪽(+z)을 본다.** (1탄 캐릭터 모델의 정면)
- 벽에 거는 가구(`frame`·`map-board`·`blackboard`·`signboard`)와 명패는 `rot` 으로 등진 벽을 정한다:
  `0`=북쪽 벽, `Math.PI`=남쪽 벽, `Math.PI/2`=서쪽 벽, `-Math.PI/2`=동쪽 벽.
- 1탄 건물·소품은 쿼터뷰 비율이라 `BUILDING_SCALE`(2.4)·`PROP_SCALE` 로 키워 쓴다. 옆으로 돌린 건물은
  가로·세로를 바꿔 만든다(`FirstPersonRenderer.buildBuildings`).

## 5. 구조에서 알아 둘 점

- **3D 와 React 분리** (1탄과 같다): `FirstPersonRenderer` 가 React 밖에서 루프를 돌리고, React 는 HUD 만.
  둘을 잇는 곳은 `src/GameScreen.tsx` 한 곳. 창이 떠 있으면 `setPaused(true)` 로 걷기를 멈춘다.
- **규칙은 순수 함수** — `src/engine/` 에 three·React 없음. 새 규칙엔 테스트를 함께.
- **벽·바닥·천장은 InstancedMesh** — 칸마다 메시를 만들지 않는다. 벽 마감(징두리·몰딩·바깥 돌 받침)은
  「어느 면이 실내에 닿았는지」로 붙인다(`buildWalls` 의 `faces`).
- **천장은 그림자를 드리우지 않는다** — 드리우면 실내가 밤처럼 어두워진다. 대신 천장 재질에 약한 자체 발광.
- **이름표 가림** — CSS2D 이름표는 벽을 뚫고 보이므로, 격자 시선 검사(`lineOfSight`)로 0.15초마다 숨긴다.
- **저사양 자동 전환** — 첫 4초 평균 프레임이 26fps 아래면 그림자를 끄고 해상도를 1로. `?low`·`?high` 로 강제.
- **진행 코드** — Crockford Base32 + 2자 검사값. 담는 것: 난이도·프롤로그·맞힌/다시 푼 퀘스트·기록 조각·
  쓴 노트 번호. **퀘스트·기록 조각의 순서가 코드의 비트 순서**이므로, 퀘스트나 조각을 **중간에 끼워 넣으면
  이미 나눠 준 코드가 깨진다.** 추가는 목록 **맨 끝**에만 하거나, `progressCode.ts` 의 `VERSION` 을 올리고
  옛 버전 해석을 남긴다.
- **저장 형식** — `imjeong-rpg2:save:v1`. 필드를 더할 때는 `emptySave()` 기본값과 `loadSave()` 병합을 함께 고친다.
- **개발용 창구** — 개발 서버에서만 `window.__game` 으로 zustand 상태에 접근(자동 화면 검사용). 배포 빌드엔 없다.

## 6. 남은 일 (우선순위 순)

### 6-1. 사실 확인 — 수업 전에 꼭 (콘텐츠 담당)

Claude 가 기억에 의존해 쓴 부분이 있다. 국사편찬위원회 한국사데이터베이스·공훈전자사료관·국가법령정보센터로
대조하고 `note`·`caveat` 를 고친다. 우선순위:

- [ ] 1919년 9월 임시헌법 **제5조**(삼권분립) 문구와 조문 번호 — `q-provisional-constitution`
- [ ] 「독립공채 상환에 관한 특별조치법」 **1983년** 제정 여부와 명칭 — `q-bond`, `relic-bond`
- [ ] 이승만 탄핵 **의결일·면직 공포일**, 공보 호수(제42호) — `q-impeach`
- [ ] 환국 **제1진(11. 23.)·제2진(12. 2.)** 명단 — `relic-return-list`
- [ ] 방순희 **1939년** 임시의정원 함경도 의원 선출 — `q-women`
- [ ] 정정화 **1990년** 건국훈장 — `q-household` 해설
- [ ] 한국독립당 결성일(1930. 1. 25.), 1927 임시약헌 공포일(3. 5.), 1940 개헌일(10. 9.) — `timeline.ts`
- [ ] 『관보』 제1호(1948. 9. 1.) 「대한민국 30년」 — `q-1948`, `relic-gazette-1948`
- [ ] 『독립신문』 창간사 「다섯 가지 사명」 요지 — `q-news`
- [ ] 건국강령 총강 발췌 문구 — `q-samgyun`
- [ ] 모든 「(요지)」 원문을 실제 원문 발췌로 바꿀 수 있으면 바꾼다

### 6-3. 실제 기기 검증 — 가장 큰 미확인 지점

작업 환경에 GPU 가 없어 소프트웨어 렌더링(SwiftShader)으로만 확인했다.

- [ ] 학교 크롬북·태블릿(아이패드·갤럭시탭)에서 프레임 확인. 느리면 `watchPerformance` 기준을 조정하거나
      `high` 품질에서도 그림자 크기(2048)·픽셀비(1.6)를 낮춘다.
- [ ] 저사양에서 걸음이 느린 문제: 한 프레임 이동을 `delta ≤ 0.08` 로 자르므로 12fps 아래에선 실제 이동이 느려진다.
- [ ] 태블릿 세로(820×1180)에서 HUD 가 좁다. 휴대폰 가로 화면은 확인하지 않았다.
- [ ] 첫 3D 적재 동안 로딩 표시가 없다 → 간단한 「장소를 짓는 중…」 표시 추가.

### 6-4. 게임성·학습

- [ ] **지표(국고·민심·외교 신망·제도·통합)가 아직 장식이다.** 선택에 따라 바뀌지만 진행·결말에 영향이 없다.

## 7. 작업 요령

```bash
npm run dev          # http://localhost:5184
npm test             # 133개
npm run typecheck
```

- 화면 확인은 Playwright 로 `?preview=…` 스크린샷을 찍으면 빠르다. 개발 서버에서는 `window.__game.getState()` 로
  상태를 바꿔 원하는 장면(에필로그 등)으로 바로 갈 수 있다.

  `npx vite --force` 로 다시 띄운다.
- 커밋 전에 **2탄과 1탄 모두** `npm run check` (1탄 `SequelCard` 를 건드렸다면 특히).
