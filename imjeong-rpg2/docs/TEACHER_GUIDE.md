# 수업 활용 안내 — 『임시정부 : 새로운 나라를 향해』 (제2탄)

## 1. 1탄과 이어서 쓰기

| 상황 | 권장 |
| --- | --- |
| 1탄을 이미 한 반 | 시작 화면에서 「🙋 해 봤어요」 → 해설사의 「📖 1탄 돌아보기」에서 **기억 퀴즈 3문제**(보너스 포인트). 퀘스트 해설마다 「🔗 1탄에서는」 상자가 같은 사건을 1탄이 어떻게 다뤘는지 알려 줍니다. |
| 1탄을 안 한 반 | 「🌱 처음이에요」 → 「📖 1탄 돌아보기」의 **1탄 줄거리 6장**을 읽고 시작. 2탄만 해도 수업이 됩니다. |
| 두 게임을 모두 할 때 | 1탄(외교·군사, 2차시) → 2탄(제도·보훈, 2차시). 1탄을 다 마치면 「다음 이야기」 카드가 2탄으로 안내합니다(1탄 `.env` 의 `VITE_SEQUEL_URL`). |

제4막(충칭)에 들어갈 때는 게임이 건너뛰는 1932~1940년(8년의 이동)을 **1탄 기억 퀴즈**로 잇습니다.
교사 화면의 「1탄 연결표」에 두 게임의 대응 장면이 정리되어 있습니다.

## 2. 권장 흐름 (45분 × 2차시)

| 차시 | 활동 | 게임 범위 |
| --- | --- | --- |
| 1차시 | 도입 5분 「나라를 세우려면 무엇이 필요할까?」 → 게임 30분 → 정리 10분: 「새 나라 설계도」와 생각 노트 1·2 발표 | 프롤로그 ~ 제2막 |
| 2차시 | 게임 30분 → 보훈의 전당에서 기부·편지·다짐 10분 → 감사 증서 인쇄·게시 5분 | 제3막 ~ 에필로그 |

**수업 끝에 꼭**: 학생에게 도움말(❓)의 **진행 코드**를 공책에 적게 하세요. 다음 시간 다른 컴퓨터에서도
시작 화면 「🔑 진행 코드로 이어하기」로 돌아옵니다. (편지·생각 노트의 글은 코드에 담기지 않습니다)

## 3. 교사용 화면 — 주소 끝에 `?teacher`

확인 번호: **0411** (임시정부 수립 기념일). ⚠ 학생이 정답표를 바로 여는 것을 막는 가벼운 문일 뿐 보안 장치가 아닙니다.

| 탭 | 쓰임 |
| --- | --- |
| 학급 진행 현황 | 학생들의 진행 코드를 한 줄에 하나씩(앞에 부름말 가능) 붙여 넣으면 기록 수·한 번에 맞힌 수·진행 막·기록 조각·생각 노트 수와 **「우리 반이 많이 틀린 문제」**를 보여 줍니다. 어디에도 전송하지 않습니다. |
| 정답·해설표 | 퀘스트 25개의 정답·핵심 사료(APA)·확인할 점. 인쇄 가능. |
| 생각 노트 질문 | 막별 질문과 살펴볼 점(루브릭 아이디어). |
| 1탄 연결표 | 2탄 퀘스트 ↔ 1탄 장면. |

학생이 더 자세한 기록을 내야 하면 감사 증서나 도움말의 **「📄 학습 기록 내려받기」**(.txt — 임무 결과·생각 노트·편지)를 과제방에 올리게 하세요.

## 4. 역사적 사고력 — 생각 노트

한 막을 마칠 때마다 정답 없는 질문이 열립니다. 채점하지 않고, 쓰면 포인트를 줍니다.

| 막 | 사고 기능 | 질문 요지 |
| --- | --- | --- |
| 1 | 비교 | 1919년 임시헌장 ↔ 오늘 헌법 제1조 |
| 2 | 인과 | 땅도 세금도 없는 정부가 연통제·공채·신문을 만든 까닭과 결과 |
| 3 | 관점 | 국민대표회의의 개조파와 창조파, 각자의 걱정 |
| 4 | 연속과 변화 | 건국강령의 약속 가운데 이루어진 것과 남은 과제 |
| 5 | 판단(시대의 눈으로) | 1948년 이시영과 김구·김규식의 서로 다른 선택 — 단정하지 않기 |
| 6 | 보훈 다짐 | 오늘 내가 할 수 있는 보훈 (감사 증서에 실림, 증서를 받으려면 필수) |

또한 퀘스트마다 **「🔎 사료 단서 먼저 보기」**로 원문을 먼저 읽고 판단할 수 있습니다 — 「증거로 생각하기」 습관을 들이게 해 주세요.

## 5. 보훈 활동

- 명패 13개: 게임에서 만난 독립유공자 12분 + **「이름을 남기지 못한 분들」**(연통제 요원·성금을 낸 동포·함께 걸은 가족).
- 편지를 쓸 때 **편지 점검표**가 ① 고마운 마음 ② 구체적인 역사 사실 ③ 오늘의 다짐이 들어갔는지 비춰 줍니다(채점 아님).
- 명패의 「이분은」 탭 → 공훈전자사료관에서 훈장 이름을 찾아 편지에 넣게 하면 조사 활동이 됩니다.
- 감사 증서 = 다짐 + 국화를 올린 분 + 편지 + 생각 노트. 인쇄해 교실에 게시하거나 포트폴리오로.

## 6. 학생 편의 (⚙️ 설정)

글자 크게 · 화면 흔들림 끄기(어지러운 학생) · 이름표 늘 보이기(저시력) · 효과음 · 둘러보기 감도.
태블릿은 왼쪽 아래 조이스틱, 길을 잃으면 「👉 데려다 주기」.

## 7. 유의 사항

- 보훈 포인트와 기부는 게임 속 활동입니다. 실제 결제 기능이 없음을 분명히 알려 주세요.
- 공용 컴퓨터라면 수업 뒤 도움말 → 「처음부터 다시」로 기록과 편지를 지워 주세요(진행 코드는 먼저 적어 두기).
- 사료 원문은 요지·발췌입니다. 원문을 제시할 때는 `docs/HISTORY_SOURCES.md` 의 자료로 판본을 확인해 주세요.
