# 수업 활용 안내 — 『임시정부 : 새로운 나라를 향해』

## 권장 흐름 (45분 × 2차시)

| 차시 | 활동 | 게임 범위 |
| --- | --- | --- |
| 1차시 | 도입 5분: 「나라를 세우려면 무엇이 필요할까?」 짝 토의 → 게임 30분 → 정리 10분: 새 나라 설계도 화면을 보며 「오늘의 대한민국에 이어진 것」 발표 | 프롤로그 ~ 제2막 |
| 2차시 | 게임 30분 → 보훈의 전당에서 기부·편지 10분 → 감사 증서 인쇄·게시 5분 | 제3막 ~ 에필로그 |

한 차시만 쓸 수 있다면 제1막(헌법)과 에필로그(보훈)만 다루고, 나머지는 과제로 이어 하게 해도 됩니다
(진행 기록은 같은 기기·같은 브라우저에서 「이어서 하기」로 이어집니다).

## 수업에서 짚을 질문

1. 1919년 임시헌장 제1조와 오늘 헌법 제1조를 나란히 놓으면 무엇이 같고 무엇이 다른가?
2. 임시정부는 왜 다섯 번이나 헌법을 고쳤을까? 그래도 바뀌지 않은 것은?
3. 건국강령의 삼균주의 가운데 오늘 실현된 것과 달라진 것은?
4. 1948년, 임시정부 요인들의 선택은 왜 갈렸을까? (한쪽을 정답으로 몰지 않기)
5. 보훈이란 무엇일까? 게임 속 기부와 실제 보훈 실천은 어떻게 다를까?

## 편지 활동 팁

- 명패의 「이분은」 탭 → 공훈전자사료관에서 훈장 이름을 찾아 편지에 넣게 하면 조사 활동이 됩니다.
- 감사 증서 화면의 「인쇄하기」로 증서와 편지를 한 장에 뽑을 수 있습니다.
- 실제로 편지를 전하려면 기념관·현충 시설 방문 계획과 함께 학교 차원에서 준비해 주세요.

## 유의 사항

- 보훈 포인트와 기부는 게임 속 활동입니다. 실제 결제 기능이 없음을 학생에게 분명히 알려 주세요.
- 공용 컴퓨터라면 수업 뒤 도움말 → 「처음부터 다시」로 기록과 편지를 지워 주세요.
- 사료 원문은 요지·발췌입니다. 원문을 제시할 때는 `docs/HISTORY_SOURCES.md` 의 자료로 판본을 확인해 주세요.
