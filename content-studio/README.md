# 콘텐츠 스튜디오 — 판매용 수업 자료 자동 생성기

주제 하나를 넣으면 **판매할 수 있는 자료 한 세트**와 **팔기 위한 문구**를 한 번에 만듭니다.

| 파일 | 내용 | 어디에 쓰나 |
| --- | --- | --- |
| `product.html` | 개념 정리 · 활동 · 활동지 · 정답과 해설 · 지도 유의점 (A4 인쇄용) | 브라우저에서 열고 "인쇄 → PDF로 저장" → **판매 상품** |
| `listing.md` | 판매처별 상품명 · 소개 · 상세 설명 · 태그 · 제안 가격 | 크몽 등 판매 페이지 등록 |
| `blog.md` | 검색 유입용 무료 글 (자료 일부 공개 + 판매 링크 안내) | 네이버 블로그 · 티스토리 |
| `sns.md` | 인스타그램 · 스레드 · 밴드 홍보 글, 숏폼 대본 | SNS 홍보 |
| `CHECKLIST.md` | 사실 검증 목록 · 저작권 · 겸직 · 정산 계좌 점검 | **판매 전 반드시 확인** |
| `kit.json` | 생성된 원본 데이터 | 다시 고치거나 다른 형식으로 바꿀 때 |

## 돈이 계좌로 들어오는 경로

```
npm run make  →  CHECKLIST 확인·수정  →  PDF 저장  →  판매처에 등록  →  구매 발생  →  판매처 정산  →  본인 계좌
                                                       ↑
                                       blog.md · sns.md 로 홍보해서 유입
```

이 도구는 **팔 물건과 홍보 문구를 만드는 단계**를 자동화합니다. 판매처 가입, 정산 계좌 등록, 업로드는 본인이 직접 합니다.
구매가 있어야 수익이 생기므로, 수익 금액이나 시점은 보장되지 않습니다.

### 참고한 글(Automaton)과 다른 점

참고 링크의 Automaton(Conway Research)은 AI 에이전트가 스스로 이더리움 지갑을 만들고, Base 체인의 USDC로 자기 서버·추론 비용을 벌어 쓰는 실험입니다.
번 돈은 우선 에이전트 자신의 운영비로 쓰이고 암호화폐 지갑에 쌓이므로, 원화 계좌로 받으려면 거래소를 거쳐야 하고 가격 변동·세금·보안 위험이 따릅니다.
또 사람의 검토 없이 AI가 돈을 쓰고 외부에 글을 올리는 구조입니다.

이 도구는 그 아이디어 중 "AI가 남이 돈을 내고 살 만한 결과물을 만든다"는 부분만 가져왔습니다.
정산은 판매처를 통해 원화 계좌로 받고, 판매 전에 사람이 내용을 확인하는 단계를 두었습니다.

## 웹 화면

claude.ai에 올린 웹 화면에서도 같은 자료를 만들 수 있습니다. **API 키가 필요 없고** 로그인한 내 Claude 계정 사용량으로 만들어집니다.

- 주소: https://claude.ai/artifact/FJTm4m77nqXEoATnZKDfuW (처음에는 본인만 열 수 있음. 공유는 페이지의 공유 메뉴에서)
- 왼쪽에 주제를 넣고 **자료 만들기** → 자료 미리보기 · 판매 문구 · 블로그 글 · SNS·숏폼 · 판매 전 체크 탭으로 결과 확인
- **자료 HTML 받기**, **전체 묶음 zip 받기**로 파일 저장. 받은 HTML은 브라우저에서 열고 인쇄 → "PDF로 저장"
- 최근 만든 자료 8개와 체크리스트 진행 상태는 그 브라우저에만 저장됩니다

화면 소스는 `web/` 에 있고, 명령줄 도구와 같은 프롬프트·스키마·렌더러(`src/`)를 씁니다. 고친 뒤에는 다시 묶어서 올립니다.

```bash
npm run build:web     # web/dist/content-studio.html 한 파일로 묶기
```

## 설치

Node.js 20 이상이 필요합니다.

```bash
cd content-studio
npm install
```

Claude API 키는 [Claude Console](https://platform.claude.com/)에서 발급받아 환경 변수로 넣습니다. 키는 저장소에 커밋하지 마세요.

```bash
export ANTHROPIC_API_KEY=sk-ant-...      # Windows PowerShell: $env:ANTHROPIC_API_KEY="sk-ant-..."
```

## 사용법

```bash
# 키 없이 결과물 모양부터 보기
npm run demo

# 자료 한 세트 만들기
npm run make -- --topic "임진왜란과 동아시아 질서의 변화" --grade "중학교 2학년" --author "동쌤"

# 학생·학부모용 자습 노트로
npm run make -- --topic "조선 후기 실학" --type study-guide --grade "고등학교 1학년"

# 주제 여러 개를 한 번에 (topics.example.txt 참고)
npm run make -- --topics-file topics.example.txt
```

결과는 `output/날짜-주제/` 폴더에 생깁니다(`output/` 은 커밋되지 않음).

| 옵션 | 기본값 | 설명 |
| --- | --- | --- |
| `--topic` | — | 주제 |
| `--topics-file` | — | 여러 주제를 한꺼번에 |
| `--grade` | 중학교 2학년 | 대상 |
| `--type` | lesson-pack | `lesson-pack`(교사용 수업 자료) / `study-guide`(학생·학부모용 자습 노트) |
| `--questions` | 10 | 평가 문항 수 (3~30) |
| `--platforms` | 크몽,자체 판매 페이지(블로그·스마트스토어) | 쉼표로 구분, 판매처마다 등록 문구를 따로 만듦 |
| `--note` | — | 추가 요청 (예: "사료 2개 포함", "탐구 질문 위주") |
| `--author` | — | 자료 하단 저작권 표시 |
| `--model` | claude-opus-5-5 | 사용할 Claude 모델 |
| `--effort` | high | `low` / `medium` / `high` — 낮출수록 빠르고 저렴 |

### 비용

자료 한 세트에 API를 두 번 부릅니다. 실행이 끝나면 그 세트의 API 비용 추정치(달러)를 보여 줍니다.
정확한 청구 금액은 Claude Console의 사용량 화면에서 확인하세요.

## 판매 전에 꼭

`CHECKLIST.md` 를 끝까지 확인하세요. 핵심만 적으면:

- **사실 검증**: AI는 연도·수치·인용을 틀릴 수 있습니다. 체크리스트에 올라온 항목은 우리역사넷·한국민족문화대백과사전 등에서 직접 확인합니다.
- **저작권**: 교과서·참고서·기출 문장을 그대로 쓰지 않도록 지시했지만, 비슷한 문장이 없는지 한 번 더 봅니다. 이미지를 넣는다면 이용 허락을 확인합니다.
- **겸직**: 현직 교원·공무원은 반복적인 판매 활동에 소속 기관의 겸직 허가가 필요할 수 있습니다. 판매 전에 학교(교육청)에 확인하세요.
- **세금**: 판매 수익은 소득 신고 대상입니다. 판매처 정산 내역을 보관해 두세요.

## 구조

```
content-studio/
├── src/
│   ├── cli.mjs        # 명령줄 옵션 처리, 여러 주제 반복, 파일 저장
│   ├── generate.mjs   # Claude API 호출 (자료 본문 → 판매·홍보 문구), 비용 추정
│   ├── prompts.mjs    # 시스템 프롬프트 (저작권·사실 검증·과장 광고 금지 규칙)
│   ├── schemas.mjs    # 구조화 출력 스키마 (zod)
│   ├── render.mjs     # HTML·Markdown 렌더러 (API 호출 없음)
│   └── sample.mjs     # --demo 용 예시 데이터
├── web/
│   ├── page.html      # 웹 화면 마크업·스타일
│   └── app.mjs        # 웹 화면 동작 (claude.ai 의 sample·downloads 기능 사용)
├── scripts/build-web.mjs  # 웹 화면을 HTML 한 파일로 묶기
└── test/render.test.mjs   # npm test
```

- 응답은 구조화 출력(JSON 스키마)으로 받아 형식이 깨지지 않습니다.
- 모델이 요청을 거절하면 서버 쪽 대체 모델로 자동 재시도합니다(`fallbacks: "default"`).
- 모델 출력은 모두 HTML 이스케이프해서 `product.html` 에 넣습니다.
