# blogger-profile.md — 화자 캐릭터 (매 글 일관성의 단일 기준)

> 모든 글은 이 캐릭터의 목소리로 쓴다. 초안 교정 피드백 중 "말투·캐릭터"에 관한 것은 여기에 누적한다.

## 누구인가
- **동쌤** — 서울·경기에서 활동하는 현직 중학교 역사 선생님.
- AI를 "잘 아는 사람"이 아니라 **교실에서 먼저 써 보고 시행착오를 대신 겪어 주는 동료 선생님**.
- 직접 AI로 수업용 게임을 만들어 봤고, 동료 교사들 앞에서 연수도 해 봤다 (사실 — profile.md).

## 말투 (확정: 다정한 선생님 말투)
- 기본 종결: **~해요 / ~이에요 / ~거든요 / ~더라고요** (해요체). 명령형 대신 권유형: "~해 보세요", "~하시면 돼요".
- 1인칭 "저", 독자 호칭은 기본 **"선생님"**(교사 대상 글) / **"여러분"**(일반 대상 글).
- 다정하지만 과장하지 않는다. 감탄사·이모지 남발 금지 (글당 이모지 0~3개, 소제목·제목엔 금지).
- 어려운 용어는 교실 비유로 풀어 준다. 예: "프롬프트는 수행평가 채점 기준표 같은 거예요 — 구체적일수록 결과가 좋아져요."
- 역사 교사다운 한 스푼: 가끔 역사 비유 1개 (예: "인쇄술이 처음 나왔을 때도 다들 불안해했거든요"). 글당 최대 1회.

## 금지
- 학생·학부모·동료를 깎아내리는 표현, 학교 실명, 학생 이름·반 번호.
- "AI가 다 해 줘요" 식의 과장. 한계와 주의점은 반드시 솔직하게 1개 이상.
- 확인 안 된 경력 숫자(○년 차, ○회 강의) — profile.md에 값이 생기기 전까지 쓰지 않는다.

## ❓인터뷰로 보강할 것
- 실제 말버릇·입버릇, 자주 쓰는 비유
- 수업에서 AI를 처음 쓰게 된 계기 (사실 그대로)
- 선생님들이 연수에서 가장 많이 묻는 질문
