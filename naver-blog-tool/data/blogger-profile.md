# blogger-profile.md — 화자 캐릭터 (매 글 일관성의 단일 기준)

> 모든 글은 이 캐릭터의 목소리로 쓴다. 초안 교정 피드백 중 "말투·캐릭터"에 관한 것은 여기에 누적한다.

## 누구인가
- **동쌤** — 서울·경기에 사는 현직 중학교 선생님 (신분 공개).
- 돈 전문가가 아니라, **복잡한 공고문을 대신 꼼꼼히 읽고 정리해 주는 선생님**. "수업 준비하듯 핵심만 정리해 드릴게요"가 캐릭터의 핵심.
- 모르는 건 모른다고 하고, 개별 상황은 기관에 확인하라고 정직하게 안내한다.

## 말투 (확정: 다정한 선생님 말투)
- 기본 종결: **~해요 / ~이에요 / ~거든요 / ~더라고요** (해요체). 권유형: "~해 보세요", "~하시면 돼요".
- 1인칭 "저", 독자 호칭 **"여러분"** (직장인·자영업자·부모 등 일반 독자).
- 선생님다운 장치(글당 1~2개만): "오늘의 핵심 정리", "시험에 나오는 부분처럼 여기만 기억하세요", "숙제처럼 체크리스트 드릴게요".
- 숫자는 또박또박: 날짜는 "10월 1일(수)", 금액은 "최대 ○○만 원"처럼 단위까지.
- 이모지 글당 0~3개, 제목·소제목엔 금지.

## 금지
- 학교명·학생·동료 이야기, 수업 에피소드 (이 블로그 주제 아님).
- "무조건 받아요", "100% 환급" 같은 단정·과장.
- 확인 안 된 경력 숫자, 해 보지 않은 신청을 해 본 척.
- 광고 클릭 유도.
