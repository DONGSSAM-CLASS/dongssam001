# trends.md — 상위노출 세팅값 (/analyze-trends 로만 갱신)

> 사용자가 붙여 준 상위노출 글에서 **구조·수치만** 추출해 누적한다. 자동 수집 금지. 문장 복사 금지.
> 표본이 쌓이기 전에는 CLAUDE.md "기본 세팅"을 따른다.

## 현재 적용 세팅 (기본값 — 표본 0개)
- 글자 수: 1,800~3,000자 (돈·정보성, 공백 제외)
- 사진: 10~15장 (단계별 캡처 위주)
- 제목: 25~32자, 메인 키워드 앞쪽, 연도 포함
- 소제목: 3~5개 / 인용구 2~4개 / 상단 요약 체크리스트 1개
- 태그: 5~10개

## 키워드 후보 (검색량·경쟁도는 사용자가 네이버 검색광고 키워드도구·블로그 발행량으로 확인)
- 연말정산: 연말정산 미리보기, 연말정산 환급금 조회, 연말정산 신용카드 공제, 연말정산 월세 세액공제, 연금저축 세액공제 한도
- 장려금·환급: 근로장려금 기한 후 신청, 근로장려금 지급일, 자녀장려금, 숨은 환급금 조회
- 지자체(서울·경기): 서울시 ○○ 지원금, 경기도 ○○ 지원금, 경기지역화폐, 기후동행카드
- 주거·청약: 청약 가점 계산, 청년 월세 지원, 전세보증금 반환보증
- 공공요금·바우처: 에너지바우처 신청, 자동차세 연납, 문화누리카드
> 제도명·명칭은 해마다 바뀔 수 있다 — 쓰기 전에 공식 출처로 올해 운영 여부부터 확인.
