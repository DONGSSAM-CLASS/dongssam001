# photo-guide.md — 필수 촬영 컷 가이드 (AI 활용법 정보 블로그)

> 사진 10~15장 목표. 사진은 파일 순서가 아니라 **스토리 순서**로 배치한다. 같은 사진 재사용 금지.
> AI 활용 글은 대부분 **화면 캡처**다. 캡처할 때 아래 개인정보부터 확인!

## 글 유형별 필수 컷

### A. 도구 사용법 / 따라 하기 (정보성)
1. 완성 결과물 (썸네일 겸 — 첫 사진)
2. 도구 첫 화면 / 가입·접속 화면
3. 실제 입력한 프롬프트가 보이는 화면 (글에는 프롬프트 원문도 텍스트로)
4. 단계별 진행 화면 3~6컷 (한 컷 = 한 단계)
5. 막히는 지점 / 오류 화면 + 해결 후 화면
6. 결과물 전·후 비교 (수정 요청 전/후)
7. 요금제·설정 화면 (무료/유료 구분이 보이게 — 캡처 날짜 기록)

### B. 수업 적용 후기
1. 수업용 결과물 화면 (학생 화면 / 교사 화면)
2. 수업 준비물·교실 세팅 (칠판, 태블릿 등 — 학생 없이)
3. 수업 장면 (학생 뒷모습·손 위주, 얼굴 나오면 전원 모자이크)
4. 학생 산출물 (이름·학번 가리기)
5. 교사용 통계/대시보드 화면 (샘플 데이터 권장)

### C. 연수·강의 후기 (섭외 목표에 가장 직접적)
1. 연수 제목 슬라이드 / 안내 게시물
2. 강의 장면 (강사 본인 — 공개 명시 전까지 모자이크 기본)
3. 실습 화면 / 참석자 실습 결과물
4. 연수 장소 외관·강의실 (기관명 공개 여부 확인)
5. 참석자 반응 (얼굴 전원 모자이크, 설문 결과는 개인 식별 정보 제거)

## 🔒 개인정보 체크 (발견 시 mosaic.js 필수)
- 학생: **얼굴(동의 여부와 무관하게 기본 모자이크)**, 이름표, 명찰, 이름이 적힌 학습지, 출석부·명렬표, 학번
- 교사/참석자: 타인 얼굴, 명찰, 휴대폰 화면 속 알림
- 화면 캡처: 이메일 주소, 계정 프로필 사진·이름, API 키·토큰, 결제 정보, 채팅방 이름, 브라우저 탭의 개인 문서명, 학교 내부망 주소
- 기타: 차량 번호판, 전화번호, 주소, 학교 교명(비공개 원칙)
- 화자 본인 얼굴도 기본은 모자이크 (사용자가 공개를 명시한 경우만 예외)

## 동영상 (input/videos/)
- 30초~2분 화면 녹화 (따라 하기 핵심 구간) 권장. 첫 text 블록 직후 자동 삽입.
- 녹화 전 알림 끄기, 개인정보 탭 닫기.
