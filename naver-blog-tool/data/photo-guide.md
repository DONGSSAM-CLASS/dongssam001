# photo-guide.md — 필수 캡처 가이드 (생활 돈 정보)

> 사진 10~15장 목표. 돈 정보 글의 사진은 대부분 **공식 사이트·앱 캡처**다. 파일 순서가 아니라 **신청 흐름 순서**로 배치. 같은 캡처 재사용 금지.
> 캡처는 PC 화면 전체보다 **필요한 영역만 잘라서** (모바일 가독성). 빨간 박스·화살표로 누를 곳 표시하면 체류시간↑.

## 신청·조회형 글 필수 컷
1. 공식 공고/안내 페이지 (기관 로고·제목·게시일 보이게 — 신뢰 + 기준일 증거)
2. 공식 사이트·앱 첫 화면 → 메뉴 위치 (단계마다 1장)
3. 로그인/인증 화면 (인증 방식 보이게, 개인정보 가림)
4. 신청서·조회 화면 입력 단계 2~4장
5. 제출 완료·조회 결과 화면 (금액·이름 가림 — 공개 동의 시 금액만 노출 가능)
6. 자주 하는 실수 화면 (오류 메시지, 놓치기 쉬운 체크박스)
7. 모바일 앱 화면 1~2장 (검색자 다수가 모바일)
8. 요약 이미지 1장 (선택: 체크리스트를 이미지로 — 직접 만든 것만)

## 비교·계산형 글 (연말정산·세금)
- 공식 계산기/미리보기 화면, 공제 항목 설명 화면, 내 입력값 예시(가상 숫자면 "예시"라고 캡션에 명시)

## 🔒 개인정보 체크 (발견 시 mosaic.js 필수)
- **이름, 주민등록번호(앞자리 포함), 주소, 계좌번호, 전화번호, 이메일, 사업자번호**
- 소득 금액·환급/납부 금액·카드 사용액 (본인이 공개를 명시하지 않으면 가림)
- 공동·간편인증서 이름, 로그인 아이디, 휴대폰 알림, 브라우저 탭의 다른 개인 문서
- 가족 정보(부양가족 이름·생년월일)
- 학교명·교직원 번호 등 직장 식별 정보
- 화자 본인 얼굴은 기본 모자이크 (공개 명시한 경우만 예외)

## 동영상 (input/videos/)
- 신청 과정 화면 녹화 30초~2분 (핵심 구간). 첫 text 블록 직후 자동 삽입.
- 녹화 전 알림 끄기, 개인정보 입력 구간은 녹화하지 않거나 잘라내기.
