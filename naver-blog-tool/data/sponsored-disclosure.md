# sponsored-disclosure.md — 협찬 표기 문구 (공정위 「추천·보증 등에 관한 표시·광고 심사지침」)

> 협찬·체험단·무상 제공·할인·제휴 수수료 등 **경제적 이해관계가 하나라도 있으면** 글 상단 **첫 블록(일반 text 블록, 인용구 아님)**에 표기한다.
> 업체가 지정한 문구가 있으면 그것이 우선. 협찬 글에 "내돈내산"·"광고 아님" 같은 거짓 부인 표현은 **위법** — 절대 금지.
> 표기는 본문과 같은 크기·잘 보이게, 한국어로, 명확하게. "소정의" "일부" 같은 모호한 표현 대신 무엇을 받았는지 구체적으로.

## 대가 유형별 기본 문구

| 유형 | 문구 |
|---|---|
| 금전(원고료) | 이 글은 {업체명}으로부터 원고료를 받아 작성했어요. |
| 무상 제공(제품·유료 AI 도구 이용권 등) | 이 글은 {업체명}으로부터 {제공 내용, 예: ○○ 유료 요금제 1개월 이용권}을 무상으로 제공받아 작성했어요. |
| 할인 | 이 글은 {업체명}으로부터 {할인 내용}을 지원받아 작성했어요. |
| 체험단 | 이 글은 {업체명} 체험단으로 선정되어 {제공 내용}을 무상으로 제공받아 작성했어요. |
| 제휴 링크(수수료) | 이 글에는 {업체명} 제휴 링크가 포함되어 있어, 링크를 통해 구매하시면 제가 일정 수수료를 받아요. |
| 혼합 | 해당 문구를 모두 나열 (예: 무상 제공 + 제휴 수수료) |

## 비협찬 글
- 협찬이 아니라면 굳이 표기하지 않는다. 필요하면 "직접 유료 결제해서 써 본 후기예요"처럼 **사실만** 적는다.
- 본인 강의·연수 홍보는 협찬이 아니지만, CTA에서 1회만.
