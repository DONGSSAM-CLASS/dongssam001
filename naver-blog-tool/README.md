# 동쌤 생활 돈 정보 블로그 자동 작성 툴 (애드포스트 수익형)

정부지원금·환급금·연말정산·세금 같은 **생활 돈 정보**를 주제로, 캡처 몇 장 + 메모 한 줄이면 → Claude Code가 **공식 출처로 사실을 대조**하고 → 네이버 상위노출 공식대로 초안을 쓰고 → 내가 승인하면 **네이버 블로그 임시저장**까지 해 줘요. 발행 버튼만 내가 누르면 끝.

- API 요금 없음 — Claude 구독(Pro 이상)으로만 돌아가요.
- **발행은 절대 자동으로 안 해요.** 진짜 발행 버튼은 코드로 막혀 있어요(발행 차단 가드).
- **숫자는 공식 출처로 검증된 것만.** 돈 글의 모든 금액·날짜·자격은 `facts`에 등록되고, 국세청·정부24 같은 1차 출처로 확인되기 전엔 임시저장이 막혀요.
- **광고 클릭 유도 문구는 자동 차단**(애드포스트 운영정책 위반 방지).
- 브라우저 자동화는 네이버 약관상 회색지대예요. 본인 계정, 하루 1~2건 수준으로만 쓰세요.

## ⚠️ 시작 전에 꼭 — 겸직허가

현직 교원이 블로그 광고 수익(애드포스트)을 얻는 건 **겸직허가 대상**이 될 수 있어요. 애드포스트 가입·수익 발생 전에 학교/교육청 기준을 확인하세요. (`data/profile.md` 참고)

## 처음 한 번만 — 설치 (내 PC에서)

1. [nodejs.org](https://nodejs.org)에서 LTS 설치 → 터미널에서 `node -v`로 확인
2. Claude Code 설치: `npm install -g @anthropic-ai/claude-code` → 터미널을 닫았다가 다시 열기
3. 이 저장소를 내려받고 `naver-blog-tool` 폴더에서 터미널 열기
4. 한 줄씩 실행: `npm install` → `npx playwright install chromium` → `claude`
5. 채팅에 `/setup-login` → 뜨는 브라우저 창에서 네이버에 직접 로그인 (비밀번호 저장 안 됨)

## 평소 사용법

1. `/topics` — 지금 써야 트래픽을 선점할 주제 추천 (시즌 2~4주 전 발행)
2. 공식 사이트 화면을 캡처해 `input/photos/`에 넣기 (개인정보는 AI가 모자이크 제안)
3. `/write 연말정산 미리보기, 협찬 아님, 작년에 세금 더 냄` → 모르는 건 되물어요
4. `/verify-facts drafts/<초안>.json` — 숫자·날짜를 공식 출처와 대조
5. 미리보기(`drafts/*.preview.html`) 확인 → "임시저장해 줘" → 네이버 **저장 글**에서 확인 후 직접 발행

`drafts/20260926-yearend-preview.json` (공백 제외 1,822자, 사진 11장 자리, 사실 20건)
- 11월 중순 서비스 오픈 전 **10월 말~11월 초 발행**을 목표로 미리 써 둔 글이에요.
- 아직 **사실 검증 0/20**, **캡처 0/11** 상태라 점검기가 일부러 막고 있어요.

## 명령 모음

| 명령 | 하는 일 |
|---|---|
| `/topics` | 시즌 캘린더 기반 다음 주제 추천 |
| `/write` | 초안 작성 → 검수 → 승인 후 임시저장 |
| `/verify-facts` | 초안의 숫자·날짜·자격을 공식 출처와 대조 |
| `/learn-style` + 잘 쓴 글 붙여넣기 | 말투·구성·심리 전략 학습 (문장은 베끼지 않음) |
| `/analyze-trends` + 상위노출 글 붙여넣기 | 글자 수·사진 수·제목 구조 세팅값 저장 |
| `/setup-login` | 네이버 로그인이 풀렸을 때 다시 로그인 |
| `npm run check -- drafts/<초안>.json` | 초안 점검 (키워드·분량·가독성·협찬·사실 검증·광고 유도) |
| `npm run preview -- drafts/<초안>.json` | 모바일 미리보기 HTML 생성 |
| `npm run draft:dry -- drafts/<초안>.json` | 저장 없이 에디터 입력만 테스트 |

## 자주 막히는 지점

- **"이 시스템에서 스크립트를 실행할 수 없으므로…"** → PowerShell에 `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` 입력 후 `Y`
- **"claude 용어가 인식되지 않습니다"** → 터미널을 닫았다가 다시 열기
- **"'&&' 토큰은 올바른 문 구분 기호가 아닙니다"** → 명령을 한 줄씩 따로 실행
- **로그인이 풀렸을 때** → `/setup-login`
- **공식 사이트를 AI가 못 읽을 때** → 공고 원문을 복사해 채팅에 붙여넣거나 캡처를 주세요
- **그 외 모든 오류** → 오류 메시지를 그대로 Claude Code 채팅에 붙여넣기

## 주의

- `naver-profile/` 폴더는 로그인 세션 그 자체예요. 절대 공유·업로드하지 마세요 (git에서도 제외됨).
- 캡처 속 이름·주민번호·계좌·주소·금액은 모자이크가 기본이에요 (`scripts/mosaic.js`, 원본은 그대로 두고 처리본을 따로 만듦).
- 상위노출·수익을 보장하는 도구가 아니라 꾸준한 발행을 돕는 도구예요. 발행 전 최종 확인과 글에 대한 책임은 작성자에게 있어요.
