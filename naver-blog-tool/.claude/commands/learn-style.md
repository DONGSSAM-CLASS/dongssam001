# /learn-style — 스타일 학습

입력: $ARGUMENTS

1. 입력이 URL뿐이면: 네이버 블로그는 WebFetch가 막혀 있을 수 있으니 재시도하지 말고 **본문을 붙여 달라고 요청**하고 멈춘다. (자동 수집 금지 — 사용자가 준 글로만 학습)
2. 글을 분석한다 — **문장을 저장하지 않고 구조만** 추출:
   - 도입 전략(첫 3문장이 독자의 어떤 상황·감정을 건드리는지, 후킹 패턴 유형)
   - 구성 흐름(소제목 순서, 정보 → 따라 하기 → 실수·Q&A → 마무리 같은 뼈대)
   - 문장 리듬(한 줄 길이, 블록당 줄 수, 인용구·사진 간격)
   - 신뢰 장치(경험 근거, 수치, 솔직한 단점, 권위 한 줄 위치)
   - 마무리 방식(관련 글 유도, 댓글 유도 — 광고 클릭 유도는 금지)
   - 우리 블로그(동쌤 캐릭터, 생활 돈 정보, 애드포스트 수익 — 체류시간·재방문)에 가져올 점 / 가져오면 안 되는 점
3. `data/style-profile.md` 학습 기록 표에 한 줄 추가하고 "누적 학습 요약"을 갱신한다. `data/blogger-profile.md`와 충돌하면 캐릭터가 우선이라고 명시.
4. 쓸 만한 권위 문구 **유형**이 보이면 `data/authority-lines.md`에 동쌤 사실 기반으로 **새로 지어서** 추가 (원문 문장 복사 금지).
5. 사용자에게 학습 요약 5줄 이내로 보고.
