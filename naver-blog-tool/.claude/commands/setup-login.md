# /setup-login — 네이버 로그인

1. `node_modules/`가 없으면 먼저 `npm install`, 브라우저가 없다는 오류가 나면 `npx playwright install chromium`을 실행한다.
2. 사용자에게 안내: "잠시 후 뜨는 브라우저 창에서 네이버에 직접 로그인해 주세요. 패스키·2단계 인증 다 돼요. 비밀번호는 제가 보거나 저장하지 않고, 로그인 세션만 `naver-profile/` 폴더에 남아요. 브라우저가 비밀번호 저장을 물으면 '저장 안 함'을 눌러 주세요."
3. `node scripts/naver_login.js` 실행 (최대 10분 대기).
4. "✅ 로그인 완료"가 나오면 성공 보고. 실패하면 오류 메시지를 보고 원인을 설명한다.
5. 주의 안내: `naver-profile/` 폴더는 로그인 세션 그 자체라 절대 공유·업로드 금지 (git에도 제외되어 있음). 이 폴더 내용은 읽지 않는다.
