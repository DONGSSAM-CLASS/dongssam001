# /topics — 다음 글 주제 추천

요청: $ARGUMENTS

1. `data/money-calendar.md`, `data/post-log.md`, `data/trends.md`, `data/profile.md`(직접 경험)를 읽는다. 오늘 날짜를 확인한다.
2. **2~6주 뒤 검색이 오를 주제**를 5개 고른다. 기준:
   - 시즌 선점(발행 후 순위가 자리 잡을 시간) > 광고 단가(세금·금융·정부지원 > 일반 생활) > 동쌤 직접 경험 가능 여부 > 이미 쓴 주제와 중복 없음
   - 서울·경기 지역 키워드로 경쟁을 피할 수 있는 주제 가산
3. 주제마다: 메인 키워드 후보 2개, 예상 페르소나 1줄, 권장 발행일, 필요한 1차 출처(기관명), 필요한 캡처 3~5개, 동쌤이 직접 해 볼 수 있는지.
4. 올해 운영 여부가 불확실한 제도는 "운영 여부 확인 필요"로 표시 (지어내지 않는다).
5. 사용자가 고르면 `/write` 로 이어가도록 안내. 검색량은 네이버 검색광고 키워드 도구에서 사용자가 확인하도록 안내 (자동 수집 금지).
