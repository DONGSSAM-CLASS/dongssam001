# /analyze-trends — 상위노출 세팅값 분석

입력: $ARGUMENTS

1. 입력이 URL뿐이면 재시도하지 말고 본문(+사진 개수, 순위)을 붙여 달라고 요청하고 멈춘다. 자동 수집 금지.
2. 글마다 측정한다 (추정이면 "추정" 표시):
   - 검색 키워드·순위, 글자 수(공백 제외), 사진 수, 동영상 유무, 지도 유무
   - 제목 길이·구조(키워드 위치, 숫자 사용, 질문형 여부)
   - 소제목 수, 인용구 수, 구분선 수, 표/체크리스트 사용
   - 메인 키워드 본문 등장 횟수, 서브 키워드 후보
   - 태그 개수(보이면)
3. `data/trends.md` 분석 기록 표에 글마다 한 줄 추가.
4. 같은 키워드 표본이 3개 이상이면 평균·범위를 계산해 "현재 적용 세팅"을 갱신하고, CLAUDE.md 기본 세팅과 다른 점을 한 줄로 적는다. 표본이 적으면 기본 세팅 유지.
5. `scripts/lib/draft.js` 점검 기준(글자 수·사진 수 범위 등)을 바꿔야 할 만큼 차이가 크면, 바로 고치지 말고 사용자에게 제안한다.
6. 보고: 핵심 수치 요약 + 다음 글에 적용할 세팅 3줄.
