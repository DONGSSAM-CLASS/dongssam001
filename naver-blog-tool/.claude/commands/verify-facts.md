# /verify-facts — 공식 출처 사실 검증

대상 초안: $ARGUMENTS

CLAUDE.md 규칙 3-2를 따른다. **추측으로 verified 를 켜지 않는다.**

1. 초안의 `sources`, `facts`, 본문을 읽는다. `node scripts/check_draft.js <초안>`으로 "facts 에 없는 숫자"가 있으면 먼저 facts 에 등록한다.
2. 각 source URL 을 WebFetch 로 연다 (정부24·복지로·홈택스·국세청·지자체·공단 등 **1차 출처만**).
   - 페이지가 동적이라 내용이 안 나오거나 차단되면 재시도하지 말고, 같은 기관의 보도자료·공지 게시판 URL 을 찾아보거나, 사용자에게 **공고 원문 붙여넣기 또는 캡처**를 요청한다.
   - 블로그·카페·뉴스 요약은 단서로만 쓰고 근거로 쓰지 않는다 (뉴스가 기관 보도자료를 그대로 인용한 경우도 가능하면 보도자료 원문을 찾는다).
3. fact 마다 판정:
   - 출처 원문과 일치 → `verified: true`, `evidence` 에 원문 핵심 문장 발췌(1~2문장), source 의 `checkedAt` 에 오늘 날짜
   - 다름 → 본문과 claim 을 출처대로 고치고 위와 같이 기록 (무엇을 고쳤는지 보고)
   - 출처에서 확인 불가 → 본문에서 그 내용을 빼거나 "공고 확인 필요"로 바꾸고 fact 삭제, 사용자에게 보고
   - 올해 공고가 아직 없음 → 작년 기준이라고 명시하거나 발행을 공고 이후로 미루자고 제안 (작년 숫자를 올해 것처럼 쓰지 않는다)
4. `basisDate` 와 본문 "○○년 ○월 ○일 기준" 문구를 검증일에 맞게 갱신한다.
5. `node scripts/check_draft.js <초안>` 재실행 → 사실 관련 오류 0개 확인.
6. 보고: 검증 표(주장 / 출처 / 결과 / 수정 내용), 확인 못 한 항목과 필요한 사용자 조치.
