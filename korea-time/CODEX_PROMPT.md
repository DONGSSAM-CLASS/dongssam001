## 기술 제약 (어기지 말 것)
- 순수 HTML + CSS + JavaScript(ES 모듈). 빌드 도구 없음.
  Vite·React·번들러·TypeScript 도입 금지. index.html 을 그대로 Hosting 에 올린다.
- 외부 라이브러리는 Firebase JS SDK(gstatic CDN) 하나뿐. 다른 CDN·웹폰트·이미지 파일 금지.
  firebase.json 의 CSP 가 이를 강제하고 있다.
- Firebase Spark(무료) 요금제 범위만 사용: Authentication + Firestore + Hosting.
  Cloud Functions·Storage 금지. 서버 로직이 필요해 보이면 보안 규칙과 클라이언트로 해결한다.
- 이미지 파일을 추가하지 않는다. 장면과 인물 초상은 js/art.js 가 SVG 로 생성한다.
  고려 시대 사진은 존재하지 않으므로 실사처럼 보이는 이미지를 만들어 붙이지 않는다
  (학생이 진짜 사진으로 오해한다). 실제 유적·유물 형태에 근거한 연출 일러스트만 쓴다.

## 내용 원칙 (어기지 말 것)
- 모든 역사 사실은 정확해야 한다. DATA_NOTES.md 의 범위 안에서 다룬다.
- 사료는 인물의 대사 '바로 아래'에 [원문 → 원문 풀이 → 쉽게 말하면 → 어려운 말 풀이 →
  APA 출처] 순서로 붙는다. ui.js 의 sourceBox() 가 이미 그려 준다.
- 출처는 교과서가 아니라 실제 원전(『고려사』 권·열전까지)을 적는다.
  validate.mjs 가 출처에 "교과서"가 들어가면 실패시킨다.
- 한문 원문이 확실하지 않으면 original 을 비우고 국역(reading)만 싣는다.
  확인되지 않은 한문을 지어 넣지 마라. 이것이 가장 큰 사고다.
- 모든 사료에 apa 와 easy(쉬운 풀이)가 반드시 있어야 한다.
- 성취기준은 2022 개정으로 편성했고, 그 이유("현행은 2015 개정이지만 올해 안에 적용을
  마치므로 계속 사용·확산을 위해 2022 개정으로 편성")를 화면에 밝히고 있다.
  standards.js 의 CURRICULUM_NOTICE 에 한 번만 정의돼 있다. 지우거나 2015 개정으로 바꾸지 마라.
- 미션은 시대순으로 잠겨 있어야 한다.
- 난이도는 중학생용(ms)/고등학생용(hs) 두 갈래. 내용과 사료, 정답은 완전히 같고
  힌트 개방 시점과 심화 문항 수만 다르다. 쉬운 쪽에서 원문이나 역사 내용을 빼지 마라.
- 퍼즐은 정답이 한눈에 보이면 안 된다. 여러 사료의 단서를 엮어야 풀리게 만든다.
  "딱 봐도 틀린 보기"를 넣지 마라. CODEX_HANDOFF.md 4.5절의 예시를 보고 그 수준을 유지해라.
- 모든 문구는 중학교 1학년도 이해할 수 있는 자연스러운 한국어로 쓴다. 어려운 낱말은
  사료의 note 에 풀이를 붙인다.
- 제작자 표기 "만든이 · 동쌤(김동은 선생님)"은 메인 화면과 결과 화면 하단에 눈에 띄지 않게
  유지한다. 크게 만들거나 지우지 마라.

## 개인정보 설계 (바꾸지 말 것)
- 학생에게서 이름·이메일·전화번호를 받지 않는다.
- 학생 로그인은 학급코드·출석번호로 만든 가상 이메일(abc123-7@koreatime.local)을 쓴다.
- 화면에 보이는 이름은 학생이 정한 별명이다.
- 학습 기록 문서 id 는 uid 가 아니라 `{classId}_{출석번호}` 다. 비밀번호를 초기화해
  uid 가 바뀌어도 기록이 이어지게 하는 장치이므로 바꾸지 마라.
- firestore.rules 는 권한 테스트 34항목을 통과한 상태다. 고치면 반드시 테스트를 다시 돌려라.

## 코드를 고친 뒤에는 반드시 이 검사를 통과시켜라
```bash
npm install                # 테스트 도구 (Playwright, Firebase 에뮬레이터)

npm run validate           # 데이터 무결성 — 정답 범위·순열·사료 참조·APA 출처
npm run serve              # 다른 터미널에서 로컬 서버 먼저 띄운다
npm run test:play          # 중·고 두 난이도 전체 플레이 (모든 퍼즐 실제 풀이)
npm run test:ux            # 저장·이어하기, 난이도별 힌트 개방, 휴대폰 화면
npm run test:rules         # Firestore 보안 규칙 34항목 (Java 필요)
```
검사를 건너뛰고 "완료했습니다"라고 보고하지 마라. 실패하면 실패한 출력을 그대로 보여 줘라.

   - 배포 후 실제 브라우저로 확인: 교사 가입 → 학급 만들기 → 6자리 코드 →
