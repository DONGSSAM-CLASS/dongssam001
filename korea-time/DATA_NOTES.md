# 역사 내용 메모 — 내용을 고치거나 늘릴 때 먼저 읽을 것

이 게임이 다루는 역사 사실의 **범위**와, 실제로 인용한 **사료 34편의 목록**입니다.
새 미션이나 퍼즐을 만들 때 이 범위 안에서 고르면 교육과정과 어긋나지 않습니다.

---

## 1. 사실 근거와 출처 원칙

- 다루는 범위는 중학교 「역사」 **‘III. 고려의 성립과 변천’** 단원의 내용 체계를 따른다.
  2022 개정 교육과정 내용 요소: **고려의 성립 / 고려의 정치적 변동과 대외 관계 /
  원 간섭기 고려 사회의 변동과 개혁 / 고려의 문화와 교류**.
- **출처는 교과서가 아니라 실제 원전을 적는다.** 교과서에 실린 사실을 확인한 뒤,
  그 사실의 원전(『고려사』 권·열전까지)을 찾아 APA 양식으로 밝힌다.
  `scripts/validate.mjs` 가 `apa` 에 "교과서"가 들어가면 검사에 실패시킨다.
- 한문 원문은 **확실한 것만** `original` 에 넣는다. 불확실하면 비우고 국역(`reading`)만 싣는다.
  확인되지 않은 한문을 그럴듯하게 지어 넣는 것이 가장 큰 사고다.
- 첨부된 교과서 PDF 에서 텍스트를 뽑을 때는 **`pymupdf`** 를 쓴다
  (`pypdf` 는 서브셋 폰트 때문에 한글이 깨진다).

## 2. 미션별로 다룬 사실

### 1장 · 고려의 건국과 정치 변화 (918~958) `[9역10-01]`
- 후삼국 성립 → 궁예가 스스로 미륵불이라 칭하고 사람을 함부로 죽임 → 신하들이 궁예를 몰아내고
  왕건을 왕으로 세움 → 고구려를 계승한다는 뜻으로 나라 이름을 **고려**(918),
  이듬해 철원에서 **송악(개경)** 으로 천도(919)
- 신라 **경순왕의 자진 항복**(935), **견훤의 항복**(935), 후백제 멸망으로 **후삼국 통일**(936)
- 거란에 멸망한 **발해 유민을 받아들여 민족의 재통합**. 호족과 6두품이 정치에 참여
  → 진골 중심 신라보다 참여 세력이 넓어짐
- **태조**: 세금 경감, 빈민 구제 기구, 호족 우대와 견제 병행, 평양을 **서경**으로 삼아
  **북진 정책**, 발해를 멸망시킨 거란 적대, **훈요 10조**(943)
- **광종**: **노비안검법**(956), **과거제**(958, 쌍기의 건의), 공신·호족 숙청 → 왕권 안정
- **성종**: **최승로의 시무 28조** 수용 → 유교 정치 이념. **2성 6부**(당의 3성 6부제를
  고려 실정에 맞게), 중추원·어사대·삼사, **도병마사·식목도감**, 대간(중서문하성 낭사+어사대)
- 지방: **12목**에 지방관 파견, 전국을 경기·**5도**(안찰사)·**양계**(병마사), 주현보다
  속현이 더 많음, 향·부곡·소, 실무는 향리. 군사: 중앙 2군 6위, 지방 주현군·주진군
- 관리 등용: 과거(제술과·명경과·잡과·승과, 제술과 중시, 무과는 거의 미시행)와 **음서**
  (왕족·공신·5품 이상 자손). 음서로 나간 사람도 과거 급제를 명예로 여김
- 비교 자료: 신라 **골품제**에 막혀 당으로 떠난 **설계두**

### 2장 · 대외 관계 (993~1107) `[9역10-02]`
- 10세기 동북아: 송의 중국 통일, 랴오허강 유역 거란의 성장 → **고려·송·거란의 다원적 국제 질서**
- 거란 1차(993): **서희 – 소손녕 담판** → **강동 6주** 확보. 거란의 진짜 목적은 고려·송 관계 단절
- 거란 2차: 개경 함락, **양규의 활약** / 거란 3차: **강감찬의 귀주 대첩**(1019)
  → 세력 균형, **나성·천리장성** 축조
- 여진: 본래 고려를 부모의 나라로 섬김 → 12세기 성장·충돌 → **윤관의 별무반**
  (기병·보병·승병) → **동북 9성**(1107) → 방어 곤란으로 반환 → 여진이 **금** 건국,
  요를 멸망시키고 송 공격, 고려에 군신 관계 요구 → 고려는 **금과 사대**하여 충돌 회피
- 교류: 송(수출 금·은·인삼·삼베·나전 칠기 ↔ 수입 비단·약재·서적), 거란·여진(농기구·곡식·포목
  ↔ 은·모피·말), 일본(인삼·곡식·서적 ↔ 유황·수은), 아라비아(수은·향신료 ↔ 금·비단).
  육로는 거란·여진이 막아 **바닷길** 이용 → **벽란도**가 국제 무역항으로 성장

### 3장 · 문벌 사회의 동요와 무신 정권 (1126~1198) `[9역10-02]`
- 12세기 문벌의 권력 독점. **경원 이씨**가 왕실과 혼인으로 80년간 외척.
  이자겸이 예종·인종에게 딸들을 시집보냄 → **이자겸의 난**(1126) → 인종이 척준경을 회유해 제거
- **묘청의 서경 천도 운동**(1135): 서경 세력(묘청·정지상) = 서경 천도·칭제건원·금 정벌 /
  개경 세력(김부식) = 개경 유지·금에 사대. 서경에 **대위국**, 연호 **천개** → 김부식의 관군에 진압
- 무신 차별: 2품 이상 불가, 같은 등급이라도 문신에게 머리 숙임, 군대 최고 지휘관도 문신
  (강감찬·윤관도 문신), 받는 토지도 적음
- **무신 정변**(1170): 정중부·이의방 등, 의종의 실정. 이후 **중방**이 최고 권력 기관
- 집권자 변천: 이의방 → 정중부 → 경대승 → 이의민 → **최충헌**(최씨 4대 60여 년:
  최충헌·최우·최항·최의). **봉사 10조**로 개혁을 내걸되 실제로는 **교정도감**(정책)·
  **정방**(인사, 최우)·**도방/삼별초**(군사)로 권력 사유화. 이규보 등 문신 등용
- 봉기: 공주 명학소 **망이·망소이**(1176), 전주 관노(1182), 운문 **김사미**·초전 **효심**(1193),
  **만적**(1198, 신분 해방, 사전에 발각). "경계(庚癸)" = 경인년 1170·계사년 1173

### 4장 · 대몽 항쟁 (1231~1273) `[9역10-02]`
- 칭기즈 칸의 부족 통일 → 거란족 반란군을 고려·몽골이 함께 격퇴 → 외교 관계 →
  몽골의 과도한 공물 요구로 갈등
- **몽골 사신 피살**(1225) → **1차 침입**(1231) → 최씨 정권 서둘러 강화 →
  **강화도 천도**(1232)
- **김윤후**: **처인성**에서 부곡민과 함께 몽골군 대장 **살리타 사살**(1232),
  뒤에 충주성에서 관노비와 함께 성을 지켜 남하 저지
- 피해: 부인사 **초조대장경** 판목 소실(1232), 황룡사 9층 목탑 소실(1238), 포로 다수
- **팔만대장경**(재조대장경) 조판 1236~1251, 현재 합천 해인사.
  장경판전은 조선 전기 건물(1995 세계문화유산), 경판은 2007 세계기록유산
- 최의 피살로 최씨 정권 붕괴 → 몽골과 강화, **개경 환도**(1270) →
  **삼별초**가 거부, 강화도 → 진도 → 제주도 → 진압(1273). 40여 년 전쟁 종결

### 5장 · 원 간섭기와 공민왕 (1270~1366) `[9역10-03]`
- **고려는 독립국의 지위를 유지했다.** (나라가 없어진 것이 아님 — 5장 첫 퍼즐의 핵심)
- 간섭: **정동행성**(일본 원정용, 고려 말까지 내정 간섭에 이용),
  **쌍성총관부**(화주)·**동녕부**(서경)·**탐라총관부**(제주)로 영토 일부 직접 지배,
  왕자가 원에서 자라고 원 공주와 혼인, **‘폐하’→‘전하’ ‘태자’→‘세자’** 호칭 격하,
  금·은·인삼·매 요구, **환관과 공녀**
- 일본 원정: 3만여 명 → 태풍으로 실패, 남송 정복 후 14만 명 → 다시 태풍으로 실패, 단념
- **몽골풍**: 철릭, ‘수라’, ‘-아치(-치)’, 변발
- **권문세족** = 친원 세력(몽골어 통역관 **조인규**, 응방 관리 **윤수**, 원에서 국왕을 모신 측근,
  공녀로 보낸 동생이 황후가 된 **기철**) + 기존 문벌 + 무신 정권기 가문.
  음서로 진출, 불법 대규모 농장 → 세금 낼 토지·백성 감소 → 재정 악화.
  충선왕·충목왕의 개혁은 권문세족 반발과 원의 간섭으로 실패
- **공민왕**(1351 즉위): 기철 등 친원 세력 제거, 정동행성 축소,
  **쌍성총관부 공격으로 철령 이북 수복**(1356), 관제·호칭 복구, 몽골식 풍습 금지,
  명 건국 후 원의 연호 중지·관계 단절, 명과 조공·책봉 수립
- 내정 개혁: **정방 폐지**, 신돈 등용 **전민변정도감**(토지와 노비를 바로잡음),
  **성균관 정비**·이색 임명 → 신진 사대부 성장의 배경
- 개혁 중단 원인: 권문세족 반발 + 홍건적·왜구 침입 + 신돈 제거·공민왕 시해.
  **원은 군사력을 동원하지 못하고 사신을 보내 항의했을 뿐** (5장 심화 문항의 핵심)
- 신흥 무인 세력: **최영**(홍산 대첩 1376), **이성계**(황산 대첩 1380),
  **최무선**(진포 대첩 1380), **박위**(쓰시마 토벌 1389). 홍건적으로 개경 함락·공민왕 안동 피란(1361)
- 신진 사대부: 성리학(**안향** 도입 → **이제현**, 만권당 → **이색** → **정몽주·정도전**),
  과거로 진출, 농장 확대와 사원 부패 비판, 토지 개혁안(이색·조준),
  고려 말 점진파와 급진파로 분열

### 6장 · 생활과 문화 `[9역10-04]`
- 가족: 일부일처제 원칙, 여자 18세·남자 20세 전후 혼인, **처가살이** 일반,
  왕실의 근친혼·동성혼, 남녀 계보 동등 중시, 음서 혜택이 사위·외손자까지,
  **남녀 균분 상속**, 부모 봉양·제사도 자녀가 나누어 맡음, 아들 없으면 딸이 제사,
  여성도 **호주** 가능, 호적에 아들딸을 태어난 순서대로·사위도 기재,
  결혼 후에도 여성의 사유 재산 인정, **재혼 자유**. 단 **관직 진출에는 제한**
- 사례: 재판관 **손변**의 판결(검은 옷·검은 관·신·종이 = 소송할 수 있는 어른의 표시),
  **박유**의 축첩 허용 주장이 여성들의 반발로 무산, 나익희의 재산 분배 사양
- 불교: 신라 말 선종 → 건국 직후 **교종** 유행 → **의천**의 해동 천태종(교종 중심 선종 통합)
  → 무신 정변 이후 선종 성장, **지눌**의 불교 개혁 운동(선종 중심 교종 포용), 송광사 중심
- 불교 예술: 하남 하사창동 철조 석가여래 좌상(대형 철불), 논산 관촉사 석조 미륵보살 입상
  (호족의 힘 과시), 「수월관음도」(고려 후기 불화, 정교·화려, 금가루)
- 건축·탑: 평창 월정사 8각 9층 석탑(송의 영향, 다각 다층), 여주 고달사지 승탑
  (신라 후기 팔각원당형 계승), 원주 법천사지 지광 국사 탑,
  개성 경천사지 10층 석탑(원의 영향, 대리석),
  안동 봉정사 극락전(현존 최고(最古) 목조 건축), 영주 부석사 무량수전(**배흘림기둥**)
- 청자: 신라 말~고려 초 송에서 기술 전래 → **순청자**(11세기) →
  **상감 청자**(12세기 중반, 상감법: 파내고 흰 흙·붉은 흙 채운 뒤 유약) →
  왜구 약탈로 강진·부안 가마 폐쇄, 수요 증가로 대량 생산 필요 → **분청사기**(고려 말).
  주전자·찻잔뿐 아니라 향로·기와·의자·베개·벼루·연적까지
- 인쇄: 목판(초조대장경 → 팔만대장경), 금속 활자 **『상정고금예문』**(1234, 부전) →
  **『직지』**(1377, 청주 흥덕사, 현존 세계 최고(最古) 금속 활자 인쇄본, 2001 세계기록유산,
  프랑스 국립도서관)
- 역사서: 건국~7대 목종 실록(부전), **『삼국사기』**(김부식, 1145, 유교적 합리주의 사관·
  신라 계승 의식) / 무신 정변·대몽 항쟁 이후 자주 의식: **「동명왕편」**(이규보, 주몽 찬양),
  **『삼국유사』**(일연), **『제왕운기』**(이승휴) — 뒤 둘은 **단군을 우리 역사의 시작**으로

## 4. 아직 게임에 안 들어간 사실 (미션을 늘릴 때 후보)

- 거란 2차 침입의 **양규** — 3장 또는 2장에 붙일 만하다 (현재 대사에서만 언급)
- **망이·망소이**(공주 명학소), **김사미·효심** 봉기 — 3장에 봉기 지도 퍼즐로 확장 가능
- **일본 원정**에 동원된 고려군과 두 차례 태풍 — 5장 심화 후보
- **최영·이성계·최무선·박위**의 홍건적·왜구 격퇴 — 6장 뒤에 ‘고려의 마지막’ 미션 후보
- **의천의 해동 천태종** 대사 — 현재 `jinul` 사료 해설 안에서만 다룸
- **부석사 무량수전 배흘림기둥**, **봉정사 극락전**, **해인사 장경판전의 과학적 원리**
  (남·북 창 크기 차이, 바닥의 숯·찰흙·모래·소금·횟가루) — 6장 문화 퍼즐 확장 후보
- **이색·조준의 토지 개혁안** 비교 — 고등학생용 심화 후보
