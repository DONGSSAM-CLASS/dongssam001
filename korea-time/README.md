# 『Let's KOREA TIME』 : 중학생을 위한 고려로의 시간여행

2022 개정 역사과 교육과정과 연계한 **고려 시대 방탈출 추리 게임**입니다.
학생은 타임머신을 타고 918년의 개경에 떨어져, 시대순으로 여섯 개의 미션을 거치며
열쇠 조각을 모으고 닫힌 시간의 문을 열어 돌아옵니다.

- 플레이 시간 **15~20분** (한 차시 수업 안에 소화됩니다)
- **중학생용 / 고등학생용** 두 갈래 — 내용은 같고 힌트와 심화 문항만 다릅니다
- 인물의 대사 바로 아래에 **사료 원문 · 쉬운 풀이 · APA 출처**를 함께 제공합니다
- 교사 모드(학급 개설 · 실시간 대시보드 · 비밀번호 초기화)와 학생 모드가 분리되어 있습니다
- 학생에게서 **이름 · 이메일 · 전화번호를 받지 않습니다**

> 만든이 · 동쌤(김동은 선생님)

## 1. 성취기준 — 왜 2022 개정인가

> 지금 학교에서 운영 중인 교육과정은 **2015 개정 교육과정**입니다.
> 다만 2015 개정 교육과정이 **올해 안에 적용을 마치기 때문에**, 이 수업 자료를 내년 이후에도
> 계속 사용하고 널리 나눌 수 있도록 성취기준은 **2022 개정 역사과 교육과정**으로 편성했습니다.

근거: 교육부. (2022). 『사회과 교육과정』(교육부 고시 제2022-33호 [별책 7]),
공통 교육과정 역사, **(10) 고려의 성립과 변천**.

| 미션 | 제목 | 시기 | 성취기준 |
| --- | --- | --- | --- |
| 1 | 만월대의 잠긴 문서고 | 918 ~ 958 | `[9역10-01]` 후삼국 통일과 체제 정비 과정을 통해 고려 성립의 역사적 의미를 탐색한다. |
| 2 | 압록강의 장막 | 993 ~ 1107 | `[9역10-02]` 고려의 정치적 변동을 파악하고 주변국과의 관계를 이해한다. |
| 3 | 흔들리는 개경 | 1126 ~ 1198 | `[9역10-02]` |
| 4 | 바다 건너 도읍, 강화 | 1231 ~ 1273 | `[9역10-02]` |
| 5 | 전하라 불린 폐하 | 1270 ~ 1366 | `[9역10-03]` 원 간섭기 고려 사회에 나타난 변화를 파악하고 개혁의 영향을 탐구한다. |
| 6 | 벽란도의 하루 | 문화와 생활 | `[9역10-04]` 고려의 문화유산과 대외 교류의 사례를 조사하여 그 특징을 파악한다. |

- 적절하고 타당한 근거를 가지고 역사적 사실에 대해 해석, 판단하기

## 2. 게임 구조

각 미션은 **① 브리핑 → ② 인물과 대화하며 단서 수집 → ③ 자물쇠(퍼즐) 풀기 → ④ 열쇠 조각 획득**
순서로 진행됩니다. 마지막에 여섯 조각이 모이면 시간의 문이 열립니다.

- 열쇠 조각: 開 · 疆 · 亂 · 抗 · 革 · 文
- 마지막 암호: 1장에서 얻은 **918**과 6장에서 얻은 **1392**를 빼서 **474** (고려가 서 있던 햇수)

퍼즐은 정답이 한눈에 보이지 않도록, 여러 사료의 단서를 엮어야 풀리게 만들었습니다. 예를 들어
- 1장 둘째 자물쇠 — 『고려사』의 “광종 9년”과 “광종 즉위 949년”을 엮어 **958**을 계산
- 2장 — 소손녕의 요구와 서희의 반박을 견주어 담판의 **논리 순서**를 재구성
- 3장 — 만적이 말한 “경계(庚癸) 이래”가 가리키는 **무신 정변(1170)**을 간지로 추론
- 5장 — 원의 간섭 사례 가운데 “고려를 없애고 원의 성으로 삼았다” 같은 **사실이 아닌 항목**을 걸러내기

### 오른쪽 위 상태창
화면 오른쪽 위에 미션 번호·제목·장소·연도·지금 할 일·자물쇠 진행·전체 진행률·모은 조각·경과 시간이
항상 떠 있습니다. 거기서 **단서 수첩**과 **이 미션의 성취기준**을 바로 열 수 있습니다.
(화면이 좁으면 상단에 붙는 띠 형태로 바뀝니다.)

### 난이도
| | 중학생용 | 고등학생용 |
| --- | --- | --- |
| 힌트 | 처음부터 열림 | 두 번 틀려야 열림 (세 번 틀리면 자동으로 열림) |
| 문항 수 | 19개 | 25개 (장마다 심화 1문항 추가) |
| 어려운 말 풀이 | 모든 사료에 제공 | 동일하게 제공 |

## 3. 사료와 출처

모든 사료는 **실제 원전**에서 가져왔습니다. 교과서를 출처로 적지 않았습니다.
인물의 대사 바로 아래에 **원문(한문) → 원문 풀이 → 쉽게 말하면 → 어려운 말 풀이 → APA 출처**
순서로 제시됩니다. 총 **34편**.

주요 원전
- 정인지·김종서 외. (1451). 『고려사』 — 세가·열전 (서희, 강감찬, 윤관, 최승로, 쌍기, 만적, 김윤후, 손변, 박유, 윤수, 조인규, 신돈, 이색 등)
- 김종서·정인지 외. (1452). 『고려사절요』 — 훈요 10조, 노비안검법
- 김부식. (1145). 『삼국사기』 — 설계두 열전
- 일연. (1281년경). 『삼국유사』 — 고조선(단군)
- 이규보. (1241). 『동국이상국집』 — 벽란도 시, 대장각판군신기고문, 음서 관련 글
- 편자 미상. 『악장가사』 — 「쌍화점」
- 지눌. (1190). 『권수정혜결사문』
- 백운화상 경한 초록, 석찬·달담 간행. (1377). 『백운화상초록불조직지심체요절』 — 간기

한문 원문이 확실하지 않은 자료는 **널리 통용되는 국역문만** 싣고 원문 표기를 하지 않았습니다.

### 그림에 대하여
고려 시대의 사진은 존재하지 않습니다. 실사처럼 보이는 이미지를 만들어 붙이면 학생이
“이게 진짜 사진”이라고 오해할 수 있으므로, **실제 유적·유물의 형태에 근거한 시네마틱 일러스트를
SVG로 직접 그려** 넣었습니다(만월대 석축과 팔작지붕의 처마 곡선, 거란 군막, 강화 해안의 성곽,
벽란도의 돛단배 등). 외부 이미지 파일이 없어 로딩 실패·저작권 문제가 없고 어떤 화면에서도 선명합니다.

## 4. 수업에서 쓰는 법 (한 차시)

1. 선생님이 **학급을 만들고** 6자리 코드를 칠판에 적습니다.
2. 학생은 `학급 코드 + 출석번호 + 비밀번호 + 별명`으로 가입합니다. **이메일을 받지 않습니다.**
3. 학생이 **수준(중학생용 / 고등학생용)** 을 고르고 시작합니다.
4. 15~20분 플레이. 선생님 화면의 대시보드가 **실시간으로** 갱신됩니다.
5. 남는 시간에 결과 화면의 「한 걸음 더 생각해 보기」 질문으로 함께 이야기 나눕니다.

- 학생이 브라우저를 꺼도 **같은 계정으로 로그인하면 이어서** 진행됩니다.
- 비밀번호를 잊은 학생은 선생님이 대시보드에서 **[비밀번호 초기화]** 를 누르면,
  같은 번호로 다시 가입해 새 비밀번호를 정할 수 있습니다. **지금까지의 기록은 그대로 이어집니다.**
- 대시보드에서 **CSV 내려받기**로 학습 현황을 엑셀로 저장할 수 있습니다.

## 5. 개인정보

- 학생에게서 **이름 · 이메일 · 전화번호를 수집하지 않습니다.**
- 학생 로그인은 학급코드와 출석번호로 만든 내부 식별자
  (`abc123-7@koreatime.local`)를 씁니다. 실제로 메일이 오가지 않는 가짜 주소입니다.
- 화면에 보이는 이름은 학생이 직접 정한 **별명**입니다. 실명을 쓰지 않도록 안내 문구를 넣었습니다.
- 저장되는 것: 학급 id, 출석번호, 별명, 수준, 진행 상황, 걸린 시간.
- 교사만 이메일로 가입합니다(비밀번호 찾기에 필요).
- 학기가 끝나면 대시보드에서 **[기록 삭제]** 로 지울 수 있습니다.
- Firestore 보안 규칙(`firestore.rules`)에서 학생은 **자기 기록만** 읽고 쓰며,
  교사는 **자기가 만든 학급의 기록만** 볼 수 있도록 막아 두었습니다.

## 6. 배포 (Firebase)

빌드 도구가 필요 없는 **순수 정적 사이트**입니다. 그대로 올리면 됩니다.

```bash
# 0) Firebase CLI 가 없다면
npm i -g firebase-tools
firebase login
```

**1) Firebase 콘솔에서 프로젝트 만들기** — https://console.firebase.google.com
- **Authentication** → 시작하기 → **이메일/비밀번호** 사용 설정
- **Cloud Firestore** → 데이터베이스 만들기 → **프로덕션 모드** (규칙은 아래에서 올립니다)
- 요금제는 **Spark(무료)** 로 충분합니다. Cloud Functions·Storage 를 쓰지 않습니다.

**2) 웹 앱 추가 후 설정값 붙여 넣기**
- 프로젝트 설정 → 내 앱 → 웹(`</>`) 추가 → `firebaseConfig` 복사
- `js/firebase-config.js` 에 붙여 넣습니다. (이 값들은 공개되어도 되는 주소입니다. 실제 보안은 규칙이 담당합니다.)

**3) 프로젝트 아이디 지정**
```bash
# .firebaserc 의 "default" 를 실제 프로젝트 아이디로 바꾸거나
firebase use --add
```

**4) 올리기**
```bash
cd korea-time
firebase deploy --only hosting,firestore:rules
```

> 설정값을 채우기 전에는 **체험 모드**로 동작합니다. 학급 기능 없이 혼자 플레이할 수 있고,
> 진행 상황은 그 브라우저에만 저장됩니다. 수업 전에 미리 해 보실 때 유용합니다.

### 로컬에서 먼저 확인하기
```bash
npx serve -l 8321 .      # 또는 python3 -m http.server 8321
# http://localhost:8321
```
ES 모듈을 쓰므로 `file://` 로 직접 열면 동작하지 않습니다. 반드시 웹 서버로 여세요.

## 7. 검사

```bash
node scripts/validate.mjs
```
정답 번호의 범위, 순서 문제의 정답이 올바른 순열인지, 사료 참조가 실제로 존재하는지,
모든 사료에 APA 출처와 쉬운 풀이가 있는지, 출처에 교과서가 적히지 않았는지를 확인합니다.

브라우저 자동 플레이 테스트(모든 퍼즐을 실제로 풀어 보는 회귀 테스트)는
`tests/` 의 사용법을 참고하세요.
