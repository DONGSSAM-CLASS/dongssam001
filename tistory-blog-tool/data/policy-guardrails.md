## 1. 구글 검색 — 스팸 정책 (Spam policies for Google web search)
원문: https://developers.google.com/search/docs/essentials/spam-policies

| 정책 | 뜻 | 이 시스템의 방어 |
|---|---|---|
| **대량 생산 콘텐츠 남용 (scaled content abuse)** — 2024-03 도입 | 사용자를 돕기보다 순위 조작이 주목적인 글을 대량으로 만드는 것. **AI든 사람이든 방법 무관.** 예: AI로 가치 추가 없이 많은 페이지 생성, 여러 페이지를 짜깁기·스크랩 | 하루 한도, `infoGain` 필수, 유사도 게이트(자카드 0.35↑ 오류), 형식·도입 반복 점검, 5개는 상한 |
| 키워드 스터핑 | 순위를 위해 키워드를 부자연스럽게 반복 | 키워드 밀도 3%↑ 오류, 2%↑ 경고 |
| 도어웨이(유입용 관문 페이지) | 지역명·키워드만 바꾼 거의 같은 페이지 여러 개 | 유사도 게이트(숫자 정규화), 같은 메인 키워드 금지 |
| 스크랩·짜깁기 | 다른 사이트 글을 가져오거나 살짝 바꿔 올림 | 타 블로그 문장 사용 금지(규칙), 벤치마킹은 구조만 |
| 얇은 제휴 페이지 | 가치 추가 없이 제휴 링크 위주 | `sponsored` 표기 강제, 제휴 글도 정보 이득 필수 |
| 사이트 평판 남용·만료 도메인 남용 | (해당 없음 — 본인 블로그) | — |

## 2. 구글 — 도움이 되는 사람 중심 콘텐츠 (helpful, reliable, people-first)
원문: https://developers.google.com/search/docs/fundamentals/creating-helpful-content

자가 질문 (quality-reviewer 채점 기준의 뼈대):
- 원본 정보·보고·연구·분석을 제공하는가? 뻔한 내용을 넘어서는 통찰이 있는가?
- 다른 출처를 참고했다면 단순 복사·재작성이 아니라 상당한 부가 가치가 있는가?
- 제목이 내용을 과장·자극하지 않고 요약하는가?
- 이 주제를 **직접 경험**했거나 잘 아는 사람이 썼다는 게 드러나는가? (E-E-A-T: 경험·전문성·권위·신뢰)
- 읽고 나서 목적을 달성했다고 느끼는가? 다시 검색하러 가야 하는가?
- 검색 유입만을 위해 특정 글자 수를 맞추거나, 잘 모르는 유행 주제를 쓰지 않았는가?
- **Who / How / Why**: 누가 썼는지(글쓴이 정보), 어떻게 만들었는지(자동화·AI 사용이 독자가 궁금해할 수준이면 밝히기), 왜 만들었는지(순위가 아니라 독자를 돕기 위해).
- **YMYL**(돈·건강·안전·법률 등 삶에 큰 영향) 주제는 신뢰 기준이 훨씬 높다 → 공식 출처·기준일·한계 명시.

## 3. 구글 — 생성형 AI 콘텐츠 안내
원문: https://developers.google.com/search/docs/fundamentals/using-gen-ai-content

- AI 사용 자체는 문제 아님. 품질·정확성·독창성이 기준.
- **AI로 가치 추가 없이 많은 페이지를 만들면 scaled content abuse 에 해당할 수 있다.**
- 정확성·품질·관련성을 사람이 책임질 것. 제목·메타데이터·이미지 대체텍스트도 정확하게.
- 독자가 "어떻게 만들었나"를 궁금해할 만하면 AI 사용을 밝히는 것을 고려 (`config.aiDisclosure`).

## 4. 애드센스 프로그램 정책 · 구글 게시자 정책
원문: https://support.google.com/adsense/answer/48182 (프로그램 정책) · https://support.google.com/adsense/answer/10502938 (게시자 정책)

| 항목 | 금지 | 방어 |
|---|---|---|
| 무효 클릭·노출 | 본인 광고 클릭, **클릭 유도**("광고 클릭해 주세요", "광고로 후원"), 광고를 가리키는 화살표·문구, 광고처럼 보이는 링크·버튼 | 클릭 유도 정규식 오류, 광고 코드는 글에 넣지 않음 |
| 게재 불가 콘텐츠 | 성인·도박·불법 약물·무기·해킹/크랙·저작권 침해(불법 다운로드)·혐오·위험 행위 조장·허위 주장 | 강한 금칙어 오류 + 민감어 경고 |
| 가치 있는 인벤토리 | 콘텐츠 없음·저가치·복제/스크랩 콘텐츠, 광고가 콘텐츠보다 많은 페이지, 탐색이 불편한 사이트 | 분량 하한(1,500자↓ 오류), 정보 이득, 유사도 게이트 |
| 오해 소지 | 낚시 제목, 사실과 다른 주장, 사칭 | 낚시어 경고, YMYL 사실 검증 게이트 |
| 저작권 | 남의 이미지·글 | 이미지 = 직접 촬영·캡처·제작만, 외부 이미지 링크 경고 |

## 5. 티스토리 (카카오)
- **Open API 글쓰기는 2024-02 종료** (https://notice.tistory.com/2664) → 자동 업로드는 브라우저 자동화뿐. 운영정책상 스팸성·반복 게시는 제재 대상 → 짧은 간격 연속 발행 금지(예약 간격 `minGapMinutes`).
- 브라우저 자동화는 약관상 회색지대 — 본인 계정, 사람 속도, 하루 한도 안에서만.

## 6. 공정위 「추천·보증 등에 관한 표시·광고 심사지침」
- 협찬·원고료·무상 제공·할인·**제휴 링크 수수료** 등 경제적 이해관계가 있으면 글 **맨 앞**에 명확히 표기. "내돈내산" 같은 거짓 부인은 위법.
- 애드센스 자동 광고는 협찬이 아님 (표기 불필요).
