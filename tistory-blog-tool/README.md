# 티스토리 애드센스 블로그 자동 작성 시스템 (Claude Code)

구글 애드센스가 붙은 **티스토리 블로그**에 **하루 최대 5개**의 글을 Claude Code가 조사·작성·검수해서 올려 주는 시스템이에요.
핵심은 "많이 쓰기"가 아니라 **구글 저품질(스팸 정책)에 안 걸리는 글만 통과시키는 품질 게이트**예요.

```
/plan  주제 대기열 2주치 설계 (시즌·클러스터·기존 글 중복 제외)
  ↓
/daily 오늘 5개 선택 → 5개 병렬 작성 → 사실 검증(돈·세금 글) → 독립 검수(100점, 80점 미만 수정·보류)
       → 품질 게이트(코드) → 미리보기·썸네일·검수 대시보드
  ↓
나    대시보드 보고 승인할 번호만 말하기  "/upload 2026-09-28 1,2,4 --schedule"
  ↓
티스토리 예약 발행 (07:40 · 10:30 · 13:10 · 18:40 · 21:20 근처로 분산)
```

- **API 요금 없음** — Claude 구독(Pro 이상, 하루 5개면 Max 권장)으로만 돌아가요.
- **공개 발행은 내가 승인한 글만.** 승인 없이 자동으로 할 수 있는 최대치는 "비공개 저장"이에요.
- **5개는 상한이에요.** 게이트·검수를 통과한 글이 3개면 3개만 올라가요. 억지로 채우지 않아요.

## 왜 이렇게 까다롭게 만들었나

구글은 2024년 3월부터 **"순위를 노리고 대량으로 찍어 낸 글"을 AI로 썼든 사람이 썼든 스팸**으로 봐요(scaled content abuse).
애드센스도 **가치가 낮거나 복제된 콘텐츠**에는 광고를 제한해요. 그래서 이 시스템은 코드로 이런 걸 막아요:

| 막는 것 | 방법 |
|---|---|
| 찍어 낸 글 (지역명·숫자만 바꾼 글) | 글끼리 유사도 계산 → 0.35 이상이면 오류 |
| 같은 키워드 글끼리 순위 갉아먹기 | 메인 키워드 중복 오류, 기존 글과 제목 유사도 경고 |
| 얇은 글 | 1,500자 미만 오류 (권장 2,000~4,500자) |
| 뻔한 요약 글 | **정보 이득(infoGain)** 필수 — 직접 경험·직접 계산·비교표·원본 캡처 중 하나 이상 |
| 틀린 돈 정보 | 돈·세금·지원금 글은 모든 숫자를 **공식 출처와 대조**해야 통과 |
| 키워드 도배 | 키워드 밀도 3% 이상 오류 |
| 애드센스 정책 위반 | "광고 클릭해 주세요" 류 문구·게재 불가 콘텐츠 오류 |
| AI 티 | "알아보겠습니다·결론적으로·다양한…" 상투어 6회 이상 오류 |
| 하루 과다 발행 | 하루 한도(기본 5), 예약 간격 90분 이상 |

정책 원문과 요약: [`data/policy-guardrails.md`](data/policy-guardrails.md)

## ⚠️ 시작 전에

- **겸직허가(현직 교원)**: 블로그 광고 수익이 겸직허가 대상일 수 있어요. 소속 기관 기준을 먼저 확인하세요.
- **결과 보장 없음**: 검색 순위·수익은 보장되지 않아요. 발행 전 최종 확인과 글에 대한 책임은 작성자에게 있어요.
- **브라우저 자동화**: 티스토리 Open API는 2024년 2월에 종료돼서, 업로드는 브라우저 자동화(Playwright)로 해요. 약관상 회색지대이니 본인 계정으로, 하루 한도 안에서만 쓰세요.

## 처음 한 번 — 설치 (내 PC, Windows 기준)

1. [nodejs.org](https://nodejs.org)에서 LTS 설치 → 터미널에서 `node -v` 확인
2. Claude Code 설치: `npm install -g @anthropic-ai/claude-code` → 터미널 닫았다 다시 열기
3. 이 저장소를 내려받고 `tistory-blog-tool` 폴더에서 터미널 열기
4. 한 줄씩: `npm install` → `npx playwright install chromium` → `npm test` (자체 테스트 22개 통과 확인) → `claude`
5. 채팅에 `/setup-blog` → 블로그 주소·주제·카테고리·필명·경험을 물어봐요
6. 터미널에서 `npm run login` → 뜨는 브라우저 창에서 카카오 계정으로 **직접** 로그인 (비밀번호는 저장 안 돼요)
   - 카카오가 "자동화 브라우저"라며 막으면 `config/blog.json`의 `"browser": { "channel": "chrome" }`으로 바꿔서 설치된 크롬을 쓰세요.
7. `npm run sync` → 블로그에 이미 있는 글 목록을 받아 와요 (중복 주제 방지·내부 링크용)
8. **첫 업로드 점검** (티스토리 화면이 바뀌었을 수 있어서 꼭 한 번):
   `/write 주제`로 글 1개 만들기 → `npm run upload:dry -- 2026-09-28 --only 1` (저장 버튼만 안 누르고 끝까지 입력) → `out/날짜/*.upload.png` 확인 → `npm run upload -- 2026-09-28 --only 1` (비공개 저장) → 티스토리 글 관리에서 서식·사진·카테고리·태그 확인

## 평소 사용법 (하루 5분)

1. `/daily` — 오늘 글을 만들어요 (5개면 30분~1시간, 그동안 다른 일 하셔도 돼요)
2. `out/날짜/index.html` 대시보드를 열어 글마다 미리보기 확인 (폰으로 봐도 돼요)
3. 고칠 게 있으면 `/review posts/날짜/02-xxx.md 도입이 너무 길어요`
4. 승인: `/upload 2026-09-28 1,2,4 --schedule` → 하루에 걸쳐 예약 발행
5. 일주일에 한 번 `/plan`으로 대기열 보충, 가끔 `/refresh`로 오래된 글 갱신

**경험을 넣어 주세요** — [`data/experience-bank.md`](data/experience-bank.md)에 실제로 해 본 것(신청해 봤다, 여기서 막혔다, 캡처 파일명)을 한 줄씩 적어 두면 AI가 그 경험만 1인칭으로 써요. 경험이 들어간 글이 구글에서도, 독자에게도 훨씬 강해요.

## 매일 자동으로 돌리기 (선택)

Windows 작업 스케줄러:
1. 시작 → "작업 스케줄러" → 작업 만들기
2. 트리거: 매일 새벽 5:30 (PC가 켜져 있어야 해요)
3. 동작: 프로그램 `powershell.exe`, 인수 `-ExecutionPolicy Bypass -File "C:\...\tistory-blog-tool\scripts\run-daily.ps1"`
4. 아침에 `out/날짜/index.html` 보고 → `claude` 열어서 `/upload 날짜 번호 --schedule`

- 자동 실행 중엔 질문을 못 하니까, 확인이 필요한 글은 **보류(held)** 로 두고 이유를 `out/날짜/report.md`에 남겨요.
- `config/blog.json`의 `pipelineMode`를 `"private-auto"`로 바꾸면 비공개 저장까지 자동으로 해요 → 티스토리 앱에서 읽어 보고 공개로 바꾸기만 하면 돼요.
- macOS/Linux: `scripts/run-daily.sh`를 cron에 등록.
- 클라우드(폰의 Claude 앱)에서는 정부 사이트·티스토리 접속이 막혀 있어서, 매일 실행은 **내 PC**에서 해야 해요.

## 처음 한 달 — 천천히 늘리기 (권장)

새 블로그나 한동안 쉬던 블로그가 갑자기 하루 5개씩 올리면 그 자체가 부자연스러운 신호예요.

| 기간 | 하루 글 수 (`dailyQuota`) | 확인할 것 |
|---|---|---|
| 1주차 | 1~2개 | 서치 콘솔에서 색인 생성되는지 |
| 2주차 | 2~3개 | 검색 노출·클릭이 생기는 글의 공통점 → `/plan`에 반영 |
| 3~4주차 | 3~4개 | 수동 조치·보안 문제 알림 없음 확인 |
| 이후 | 최대 5개 | 검수 점수 평균 85점 이상 유지될 때만 |

같이 해 두면 좋은 것:
- **구글 서치 콘솔**에 블로그 등록 → 사이트맵(`https://내블로그.tistory.com/sitemap.xml`) 제출. 티스토리 관리 > 플러그인에 구글 서치 콘솔 연동이 있어요.
- **애드센스 광고 설정**: 티스토리 관리 > 수익 > 애드센스에서 자동 광고 + 본문 상단·중간·하단 배치. 글 안에 광고 코드나 "광고 클릭" 문구는 절대 넣지 않아요.
- 키워드 검색량 확인: 구글 키워드 플래너·구글 트렌드, 네이버 데이터랩 (AI가 검색량을 추측하지 않아요).

## 명령 모음

| 명령 | 하는 일 |
|---|---|
| `/setup-blog` | 처음 설정 인터뷰 (주소·주제·카테고리·화자·운영 방식) |
| `/plan [개수 분야]` | 주제 대기열 설계 (클러스터·시즌·우선순위) |
| `/daily [날짜 개수]` | 오늘 글 파이프라인 전체 |
| `/write <주제 · 메모>` | 글 1개 바로 쓰기 |
| `/verify <글|날짜>` | 돈·세금 글 사실 재검증 |
| `/review <글|날짜> [피드백]` | 수정·재검수 |
| `/upload <날짜> [번호] [--schedule]` | 티스토리 업로드 (기본 비공개 저장) |
| `/refresh` | 오래된 글 갱신 원고 |

| 터미널 | 하는 일 |
|---|---|
| `npm run check -- <날짜|글>` | 품질 게이트 |
| `npm run build -- <날짜|글>` | HTML·미리보기·썸네일·대시보드 |
| `npm run queue -- stats` | 대기열 현황 |
| `npm run upload:dry -- <날짜> --only 1` | 저장 없이 입력만 테스트 |
| `npm run probe` | 티스토리 화면 구조 진단 (업로드가 셀렉터 문제로 실패할 때) |
| `npm run login` / `npm run sync` / `npm test` | 로그인 / 기존 글 동기화 / 자체 테스트 |
| `node scripts/youtube_info.js <주소>` | 참고 유튜브 영상의 제목·설명·챕터·댓글 |

## 자주 막히는 지점

- **PowerShell "스크립트를 실행할 수 없으므로"** → `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` → `Y`
- **"claude 용어가 인식되지 않습니다"** → 터미널 다시 열기. 작업 스케줄러에서 안 되면 `run-daily.ps1`의 `claude`를 전체 경로(`where.exe claude` 결과)로 바꾸기
- **업로드 "로그인이 필요합니다"** → `npm run login`
- **업로드가 버튼·입력란을 못 찾음** → 티스토리 화면이 바뀐 거예요. Claude Code에 "업로드 실패 고쳐 줘"라고 하면 `npm run probe`로 실제 화면을 떠서 고쳐요
- **"편집기에 다른 원고가 이미 있습니다"** → 티스토리 글쓰기 화면의 자동저장 원고를 직접 정리한 뒤 다시
- **공식 사이트를 AI가 못 읽을 때** → 공고 원문을 복사해 채팅에 붙여넣거나 캡처를 주세요

## 주의

- `.auth/` 폴더는 로그인 세션 그 자체예요. 절대 공유·업로드하지 마세요 (git에서도 제외돼요).
- 사진은 직접 찍거나 캡처하거나 만든 것만. 캡처 속 이름·주민번호·계좌·주소·금액은 가려 주세요.
- 벤치마킹할 글을 보여 줄 때는 구조만 배우고 문장은 가져오지 않아요.

## 참고한 자료

- 사용자가 준 유튜브 영상: 조코딩 「바이브 코딩 기초, 수익형 웹 사이트 만들고 돈 벌기」(2026-01-23) — 제목·설명·챕터·댓글로 확인(자막 전문은 못 받음). 티스토리 자동화가 아니라 **직접 만든 웹사이트에 애드센스를 붙이는 강의**라, 이 시스템에는 애드센스 주의 사항 쪽만 해당돼요 (이미 `data/policy-guardrails.md`에 반영).
  - 다른 영상도 참고하려면: `node scripts/youtube_info.js <유튜브 주소>` (제목·설명·챕터·인기 댓글). 대본까지 필요하면 내 PC에서 `yt-dlp --skip-download --write-auto-subs --sub-langs ko <주소>`.
- 티스토리 에디터 셀렉터: 공개 오픈소스 [Jinxxlog/auto_tstory](https://github.com/Jinxxlog/auto_tstory), [kgbae99/tistory-blog-auto](https://github.com/kgbae99/tistory-blog-auto)의 2026-09 실측값 (코드는 새로 작성)
- 구글 검색 센터 스팸 정책·도움이 되는 콘텐츠·생성형 AI 안내, 애드센스 프로그램 정책 — 링크는 `data/policy-guardrails.md`
