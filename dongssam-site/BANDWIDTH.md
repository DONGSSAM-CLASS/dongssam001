## 새 아이콘을 추가할 때

`index.html`, `app.js`, `projects.js`에 새로운 아이콘 이름을 추가한 뒤 다음 명령으로 아이콘 묶음을 갱신하고 함께 배포하세요.

```sh
cd tools
npm ci
npm run build:icons
```

캐시 중인 이미지 내용을 바로 교체해야 한다면 파일명을 바꾸고 참조도 갱신하세요. 파일명에 콘텐츠 해시를 붙이는 방식이 안전합니다.

## 배포 범위와 한계

운영 중인 최신 HTML/JS/CSS와 다른 파일은 Firebase의 기존 파일 해시를 재사용해 보존했습니다. 특히 운영 `styles.css`는 이 저장소 파일과 해시가 달랐으므로 이번 배포에서 덮어쓰지 않았습니다. 전체 사이트를 다시 배포하기 전 최신 CSS를 확보해야 합니다.

역사 레이싱은 동일 프로젝트의 별도 사이트입니다. 그 사이트에도 정적 미디어의 7일 캐시를 적용했으며, 파일 168개의 내용은 변경하지 않았습니다. GitHub에서 확인한 레이싱 소스(9월 24일)가 운영본(10월 2일)보다 오래되어 운영 기능을 과거 버전으로 되돌리지 않았습니다. 추가 에셋 압축·불필요 파일 제거는 최신 소스 확보 후 가능합니다.

이미 소진한 월간 전송량은 최적화나 재배포로 초기화되지 않습니다. 10월 30일 배포 후에도 두 URL은 HTTP 509를 반환합니다. 다음 달 한도 초기화 후 절감 효과가 적용되며, 신규 방문이 많으면 무료 한도는 다시 초과할 수 있습니다.
