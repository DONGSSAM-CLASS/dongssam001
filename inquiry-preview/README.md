# 동쌤 역사 탐구실 개발 미리보기

6개 탐구 활동을 자료 읽기·근거 작성·교사 검토 흐름으로 살펴보는 정적 미리보기입니다.
유료 서비스 완성본이 아니며, 실시간 제출·계정 인증·이용권·결제 기능은 포함하지 않습니다.

## 실행

저장소 루트에서 `python3 -m http.server 8080`을 실행하고
`http://localhost:8080/inquiry-preview/`를 여세요.
외부 라이브러리와 이미지·폰트 파일 없이 동작합니다.

## 자료 처리

학생 답안은 이용 중인 브라우저의 localStorage에 저장합니다.
교사는 학생이 제출한 JSON 파일을 자신의 브라우저에서 불러옵니다.
답안 파일을 서버로 전송하지 않습니다. 실제 수업에서는 공동 기기 사용 후 답안을 지우세요.
CSV의 수식 시작 문자는 텍스트로 처리하고, 가져온 답안은 HTML로 해석하지 않습니다.
출처 링크를 누르면 해당 외부 사이트로 이동합니다.

## 공개하는 내용

이 폴더의 HTML·CSS·JavaScript와 검증용 코드만 이번 변경으로 추가합니다.
학교·학생·후원자의 실제 자료, 복원한 게임 배포본, 3D 모델·이미지,
Firebase 설정·권한 규칙, 운영용 인증 정보는 추가하지 않습니다.
원래 저장소에 이미 공개되어 있던 파일의 공개 상태는 바꾸지 않습니다.
백과사전 원문·이미지는 복제하지 않고 출처 링크를 제공합니다.
