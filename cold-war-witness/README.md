# 냉전의 목격자 — 감시 속에서 내리는 선택

냉전 시대를 살아가는 **평범한 시민(가상 인물)** 이 되어 선택을 내리고, 그 경험을 **AI 윤리 원칙**과 잇는 중학교 2학년 역사 3차시 수업용 웹앱입니다.

- 출품: 2026 인공지능 윤리교육 콘텐츠 공모전 (주최: 과학기술정보통신부·정보통신정책연구원)
- 개발: 동쌤 김동은 (번동중학교)
- 교과: 중학교 역사① (2022 개정) [9역07-01] [9역07-02] · 한국형 사회정서교육 교육과정(2025) 연계
- 윤리원칙: 「대한민국 인공지능 윤리원칙」 3대 가치 + 7대 원칙

| 차시 | 챕터 | 인물(가상) | 받는 원칙 카드 |
|---|---|---|---|
| 1 | 「슈타지의 벽」 1980년대~1992년 동베를린 | 인쇄소 직원 카트린 뮐러 | 🔒 프라이버시 보호 · 🧑 인간중심성 |
| 2 | 「명단에 오른 이름」 1950~1954년 뉴욕 | 라디오 대본 작가 헬렌 브룩스 | ⚖️ 공정성·포용성 · 📋 책임성 |
| 3 | 「13일간의 선택」 1962년 10월 플로리다 | 지역 신문 기자 마리 에번스 | ✅ 신뢰성 · 🛡️ 안전성 · 🔍 투명성 |
| 3 후반 | 나의 AI 윤리 실천 선언문 + 인증서 | | |

## 1. 무엇이 들어 있나요

**학생 화면**
- 입장: 학급 코드 → 번호·닉네임 → PIN 4자리 (실명·이메일·전화번호를 받지 않음, 익명 로그인)
- 다른 기기에서 이어 하기: 학급 코드 + 번호 + PIN
- 챕터: 인트로 → 장면 1~5 (감정 체크 → 선택 → 선택 결과 → “실제 역사에서는?” 사실 카드) → AI 시대 연결 성찰 → 원칙 카드 획득 → 챕터 마무리(학급 선택 분포, 마음 돌아보기) → 완료 도장
- 쓰기 칸마다 글자 수 표시와 **문장 시작 도우미**(누르면 칸에 들어가는 첫 마디)
- 원칙 카드 도감, 선언문(카드 보드 + 3대 가치), 인증서(인쇄·이미지 저장)
- 진행은 장면마다 자동 저장, 선택에는 점수·정답 없음

**선생님 화면**
- Google 로그인, 여러 학급 만들기(6자리 코드 자동 발급)
- 수업 진행 스위치: 챕터 1~3·선언문 잠금/해제, 선택 분포 학생 공개
- 진행 현황(실시간), 선택 분포 막대그래프(화면 공유용 큰 글씨), 성찰·선언문 열람과 ⭐ 하이라이트, 발표 모드
- CSV 내보내기, 학생 PIN 초기화(임시 PIN), 학급 삭제(두 번 확인, 데이터 파기)
- 수업 자료: 3차시 교수·학습 과정안, 차시별 활동지, 교사용 가이드, 교육과정 연계표 (A4 인쇄·PDF 저장)

**기술**: Vite + React 18 + TypeScript + Tailwind CSS 4 · Firebase(Authentication, Cloud Firestore, Hosting) — **무료 Spark 요금제만 사용**. Cloud Functions·유료 기능·외부 AI API·외부 분석 도구(GA 등) 없음.

## 2. Firebase 설정 — 선생님이 콘솔에서 할 일

> 처음 한 번만 하면 됩니다. 20분 정도 걸려요.

### 2-1. 프로젝트 만들기
1. <https://console.firebase.google.com> 에 Google 계정으로 로그인합니다.
2. **프로젝트 추가** → 이름 입력 (예: `cold-war-witness`) → **Google 애널리틱스는 끕니다**(학생 개인정보 보호).
3. 요금제는 **Spark(무료)** 그대로 둡니다.

### 2-2. 로그인 방법 켜기 (Authentication)
1. 왼쪽 메뉴 **빌드 → Authentication → 시작하기**
2. **로그인 방법** 탭에서 두 가지를 **사용 설정**합니다.
   - **Google** (선생님용) — 프로젝트 지원 이메일을 고르고 저장
   - **익명** (학생용)
3. **설정 → 승인된 도메인**에 배포 주소(`프로젝트ID.web.app`, `프로젝트ID.firebaseapp.com`)가 있는지 확인합니다. 다른 주소로 쓰면 여기에 추가합니다.

### 2-3. 데이터베이스 만들기 (Firestore)
1. **빌드 → Firestore Database → 데이터베이스 만들기**
2. 위치: **`asia-northeast3` (서울)** — 나중에 바꿀 수 없어요.
3. **프로덕션 모드**로 시작합니다. (보안 규칙은 3단계에서 배포합니다.)

### 2-4. 웹 앱 등록 → 설정값 복사
1. **프로젝트 설정(톱니바퀴) → 일반 → 내 앱 → 웹(`</>`)** 으로 앱을 추가합니다. (Hosting 설정 체크는 하지 않아도 됩니다.)
2. 나오는 `firebaseConfig` 값을 `cold-war-witness/.env.local` 파일에 옮겨 적습니다.

```bash
cd cold-war-witness
cp .env.example .env.local
# .env.local 을 열어 아래 값을 채웁니다
VITE_FIREBASE_API_KEY=...
VITE_FIREBASE_AUTH_DOMAIN=프로젝트ID.firebaseapp.com
VITE_FIREBASE_PROJECT_ID=프로젝트ID
VITE_FIREBASE_STORAGE_BUCKET=...
VITE_FIREBASE_MESSAGING_SENDER_ID=...
VITE_FIREBASE_APP_ID=...
VITE_USE_EMULATOR=
```

> 이 값들은 비밀번호가 아니라 “어느 프로젝트에 연결할지” 알려 주는 주소입니다. 데이터는 보안 규칙이 지킵니다. 그래도 `.env.local` 은 git 에 올라가지 않게 되어 있습니다.

### 2-5. 프로젝트 ID 연결
`cold-war-witness/.firebaserc` 의 `"default"` 값을 내 프로젝트 ID 로 바꿉니다.

```json
{ "projects": { "default": "내-프로젝트-ID" } }
```

## 3. 배포하기

컴퓨터에 **Node.js 20 이상**이 있어야 합니다.

```bash
cd cold-war-witness
npm install
npx firebase login            # 처음 한 번 (브라우저가 열리면 같은 Google 계정으로 로그인)
npm test                      # 콘텐츠·계산 점검 (29개 통과해야 함)
npm run deploy                # = 빌드 + Hosting 배포 + Firestore 보안 규칙 배포
```

끝나면 `https://프로젝트ID.web.app` 주소가 나옵니다. 이 주소를 학생에게 알려 주세요.

**배포 뒤 꼭 확인할 것**
1. 선생님 화면에서 Google 로그인이 되는지 (팝업이 막히면 주소창 오른쪽에서 팝업 허용)
2. 학급을 만들고, 다른 기기(또는 시크릿 창)에서 학생으로 입장해 장면 1까지 해 보기
3. 선생님 화면 ‘진행 현황’에 그 학생이 보이는지

> 보안 규칙만 다시 올리려면: `npx firebase deploy --only firestore:rules`

## 4. 수업에서 쓰기

자세한 발문·예상 반응·유의점은 앱의 **선생님 화면 → 수업 자료 → 교사용 가이드**에 있습니다(인쇄 가능).

1. **수업 전**: 학급 만들기 → 학급 코드를 칠판에 적기 → 인쇄 자료(과정안·활동지) 준비
2. **수업 시작**: 그 차시 챕터만 스위치로 **열기**
3. **수업 중**: ‘진행 현황’에서 멈춘 학생 돕기 → ‘선택 분포’를 화면에 띄워 토론 → 필요하면 ‘선택 분포 학생 공개’ 켜기
4. **정리**: ‘성찰·선언문’에서 좋은 답변에 ⭐ → ‘발표 모드’(닉네임은 기본으로 가림)
5. **3차시 후반**: ‘선언문’ 스위치 열기 → 학생이 선언문 제출 → 인증서 인쇄/이미지 저장
6. **학기 끝**: ‘학급 관리’ → CSV 내려받기 → **학급 삭제**(데이터 파기)

**학생이 PIN 을 잊었을 때**: ‘학급 관리 → PIN 초기화’ → 화면에 나온 임시 PIN 을 알려 주면, 학생은 ‘다른 기기에서 이어 해요’로 들어옵니다. 기록은 그대로 남아요.

**선택 분포 공개는 선생님 화면이 열려 있을 때 갱신됩니다.** (서버 기능 없이 무료로 운영하기 위해, 선생님 화면이 숫자를 모아 올립니다.)

## 5. 문장 고치기 (코드를 몰라도 됨)

역사 콘텐츠와 수업 자료는 모두 `src/data/` 에 있습니다. 따옴표 안의 문장만 고치면 됩니다.

| 고칠 것 | 파일 |
|---|---|
| 장면 본문·선택지·결과·성찰 질문·문장 시작 도우미 | `src/data/scenarios.ts` |
| 사실 카드와 출처 | `src/data/facts.ts` |
| 원칙 카드 설명·냉전 연결 한 줄·3대 가치 | `src/data/principles.ts` |
| 교육과정 원문(성취기준·K-SEL 역량) | `src/data/curriculum.ts` |
| 과정안·활동지·교사용 가이드 | `src/data/lessonMaterials.ts` |
| 앱 정보(공모전) 페이지 | `src/data/appInfo.ts` |
| 감정 체크 5종 | `src/data/emotions.ts` |
| 앱 제목 | `src/config.ts` 의 `APP_TITLE` |

**지켜 주세요**
- 사건·날짜·수치·실존 인물의 행동은 사실 카드(`facts.ts`)에만 씁니다. 실존 인물의 말은 따옴표로 직접 인용하지 않습니다.
- `id`(예: `ch1-s1`, `ch1-q1`, `'a'`)는 저장 데이터·보안 규칙과 이어져 있어 바꾸면 안 됩니다. 장면·질문을 **추가**하려면 `firestore.rules` 의 id 목록도 같이 고쳐야 합니다.
- 고친 뒤 `npm test` → 통과하면 `npm run deploy`

`npm run facts:doc`, `npm run curriculum:doc` 로 검토용 표(`docs/fact-cards.md`, `docs/curriculum-map.md`)를 다시 만들 수 있습니다.

## 6. 개발·테스트

```bash
npm install
npm run emulators      # 터미널 1: 로컬 Firebase 에뮬레이터 (Auth 9099, Firestore 8080)
npm run dev:emu        # 터미널 2: 에뮬레이터에 붙은 개발 서버 http://localhost:5173
```

| 명령 | 내용 |
|---|---|
| `npm test` | 콘텐츠 구조 점검 + 계산 함수 단위 테스트 (29개) |
| `npm run test:rules` | **보안 규칙 테스트** — 에뮬레이터를 스스로 켜고 끔 (39개) |
| `npm run e2e` | 브라우저 전체 흐름 + 키보드 조작 + 접근성(axe, WCAG 2.1 AA) 점검. 에뮬레이터와 `dev:emu` 가 켜져 있어야 함. 처음 한 번 `npx playwright install chromium` |
| `npm run build` | 타입 검사 + 배포용 빌드 |

에뮬레이터 개발 중 선생님 로그인은 Google 대신 에뮬레이터의 가짜 계정 화면이 뜹니다(“Add new account”).

## 7. 개인정보·보안

- 학생: 익명 로그인 + 번호 + 닉네임. 실명·이메일·전화번호를 받지 않습니다. 입장 화면에 “실명 대신 번호와 닉네임만 입력하세요” 안내.
- **PIN 은 원문을 저장하지 않습니다.** 학생 기록의 문서 주소가 `SHA-256(앱 고유 문자열:학급:번호:PIN)` 이라서, PIN 을 아는 사람만 그 기록을 찾아 다른 기기로 옮길 수 있습니다.
- 보안 규칙(`firestore.rules`): 학생은 자기 기록만, 교사는 자기가 만든 학급만. 학급 코드는 한 건 조회만(목록 조회 금지). 모든 쓰기에서 필드 이름·타입·길이 검증(서술형 최대 500자). 한 번 고른 선택·감정은 바꿀 수 없음.
- 학급 삭제 시 학생 기록·자리·멤버·통계·하이라이트·코드·학급을 모두 지웁니다.
- 외부 분석 도구·광고·외부 AI 호출 없음. 보안 헤더(CSP 등)를 `firebase.json` 에 설정.

## 8. 알려진 한계

- **PIN 은 4자리**라서, 같은 반 학생이 작정하고 1만 번을 시도하면 뚫릴 수 있습니다(서버 기능 없이는 시도 횟수를 막을 수 없음). 의심되면 PIN 초기화로 바로 막을 수 있습니다.
- **번호를 잘못 골라 들어온 학생**의 기록을 선생님이 지우는 기능은 명세에 없어 넣지 않았습니다. (제안: `docs/work-log.md`)
- **선택 분포 학생 공개**는 선생님 화면이 열려 있는 동안 갱신됩니다.
- 무료 요금제 한도(하루 읽기 5만·쓰기 2만) 안에서 여러 학급이 동시에 써도 넉넉합니다(학생 30명 한 차시 ≈ 쓰기 600회 안팎).
