# SUPERSTAR KART 확장판 — 진짜 3D 카트 레이싱 게임 제작 지시

아래 요구사항을 **전부 충족하는 3D 카트 레이싱 게임**을 만들어줘.
모바일 카트레이싱 게임(카트라이더 러쉬 스타일)을 웹에서 돌아가게 하는 것이고,
**반드시 실제 3D로 만들어야 한다.** 아래 "기술 요구사항"을 위반하면 실패다.
출력물은 코드 파일 `superstar-kart.html` 단 하나다.

## 0. 기술 요구사항 (최우선, 위반 금지)

- **진짜 3D 렌더링**: Three.js(WebGL)를 CDN에서 로드해서 사용한다.
  - `THREE.PerspectiveCamera` 3인칭 추적 카메라(플레이어 뒤 8~9유닛, 위 3.5유닛, lerp 부드럽게 추적)
  - `THREE.CatmullRomCurve3`(닫힌 곡선)로 트랙 중심선을 만들고, 중심선 ±7유닛 폭의 **리본 메시**로 도로를 생성 (BufferGeometry 수작업 구성, UV로 아스팔트 텍스처 반복)
  - CanvasTexture로 아스팔트(노이즈 + 가장자리 적/백 커브 + 중앙 점선) 직접 생성
  - HemisphereLight + DirectionalLight, Fog, 하늘색 배경
  - **2D 캔버스 위조, CSS 트릭, 이미지 가짜 원근법 금지** — 오브젝트는 전부 3D 메시(Box/Cone/Cylinder/Sphere)로 만든다
- **단일 HTML 파일**(`superstar-kart.html`)로 모든 CSS/JS를 인라인. 외부 파일 없이 브라우저 더블클릭으로 실행 가능해야 한다. 빌드도구/npm 설치 불필요.
- 게임 루프는 `requestAnimationFrame` + delta time 기반. 60fps 목표.
- UI와 모든 텍스트는 **한국어**. 모바일 세로 화면을 기준으로 한 UI 배치(반응형).

## 1. 게임 흐름 (7개 화면, 정확히 이 순서)

1. **타이틀**: 큰 이탤릭 골드 그라데이션 로고 "SUPERSTAR KART", 부제 "역사 속 영웅들의 카트 레이싱 · 8인 레이스", [레이스 시작] 노란 버튼
2. **레이서 고르기 (1/2)**: 왼쪽 큰 프로필(얼굴/이름/역할/필살기 설명 + 능력치 바 4개: 최고 속도·가속·핸들링·무게), 오른쪽 5열 캐릭터 카드 그리드 10장, 하단에 [내 이름] 입력란(기본값: 선택한 캐릭터 이름, 최대 8자) + [차량 선택]/[다음] 버튼
3. **차량·코스·난이도 선택 (2/2)**: 왼쪽 3D 미리보기(노란 링 받침대 위 차량), 오른쪽에 세 그룹 — "어떤 차로 달릴까요?" 차량 카드 5장 / "어느 코스에서 달릴까요?" 트랙 카드 2장 / "어떤 난이도로?" 난이도 카드 3장, 하단 [완료]
4. **로딩**: "SUPERSTAR KART / RACE STARTING" 카드, YOUR RACER(캐릭터·역할·DRIVER 이름) / UP NEXT(트랙 이름·설명·선택 난이도 표시) 두 박스, 프로그레스 바 + "코스를 만드는 중... N%" 단계별 문구, 하단 랜덤 팁
5. **레이스**: 3-2-1-GO! 카운트다운(카운트다운 중 팁 배너: "GO 직전에 드리프트 버튼을 누르면 로켓 스타트!") → 주행 → 3랩 완주
6. **결과**: "🏆 챔피언!" / "포디움 피니시!" / "RACE FINISH!" + 8인 최종 순위표(메달, 내 기록 강조, 트랙명·난이도 표기) + [다시 달리기]/[처음으로]

## 2. 캐릭터 10인 (실제 역사 인물 — 반드시 이 구성)

한국사 5인: 세종대왕(조선의 제4대 왕), 이순신(조선 수군 통제사), 신사임당(조선의 화가·시인), 유관순(3·1운동 독립운동가), 김유신(신라 삼국통일의 장군)
세계사 5인: 클레오파트라(고대 이집트의 여왕), 나폴레옹(프랑스의 황제), 징기스칸(몽골 제국의 대칸), 다 빈치(르네상스의 천재), 잔 다르크(오를레앙의 성녀)

- 각 캐릭터: 고유 색상, 이모지 심볼, 능력치(top/acc/hand/wt를 0~1 값, 합이 크게 차이 나지 않게 트레이드오프)
- 캐릭터는 3D로 표현: 원통 몸통 + 구형 머리 + 머리색 구체, 카트 위에 탑승, 머리 위 한글 이름표 스프라이트
- **필살기**(아래 3절)도 캐릭터별로 정의

## 3. 필살기 시스템 (캐릭터별 고유기)

- 필살기 게이지(보라색, HUD 좌상단)가 주행 중 천천히, **드리프트 중 4배 이상 빠르게** 충전. 100%가 되면 점멸 애니메이션.
- 발동: 키보드 `E` 또는 터치 ⚡ 버튼. AI도 게이지가 차면 자동 발동(난이도에 따라 발동 확률 다름).
- 캐릭터별 필살기 (이름·효과 그대로 구현):
  - 세종대왕 **훈민정음**: 유물 아이템 즉시 획득 + 부스터
  - 이순신 **학익진**: 2.5초 무적 + 부스터
  - 신사임당 **초충도**: 앞 라이벌 2명을 2.5초 감속(나비 이펙트)
  - 유관순 **대한독립만세**: 부스터 + 2초 무적
  - 김유신 **화랑 질주**: 부스터 중 접촉한 상대 스턴
  - 클레오파트라 **나일의 유혹**: 모든 상대 2초 감속
  - 나폴레옹 **대륙군 포격**: 포탄 3발 부채꼴 연사
  - 징기스칸 **기마 돌격**: 강력 부스터 + 접촉 스턴
  - 다 빈치 **공중 비행**: 4초 최고속도 상승 + 오프로드 감속 무시
  - 잔 다르크 **오를레앙의 깃발**: 스턴 즉시 해제 + 3초 무적
- 상태 이상 구현: 스턴(머리 위 회전 별, 감속), 무적(아이템/함정/스턴 모두 무시), 감속 디버프

## 4. 아이템 — 역사 유물 4종

초록빛 "?" 반투명 회전 박스를 트랙 위 5곳 × 3레인에 배치(획득 시 사라졌다 3.5초 후 재생성).

| 유물 | 효과 |
|---|---|
| 🏹 신기전 (조선의 로켓 화살) | 전방 직진 발사, 명중 시 스턴 1.6초 |
| 🐢 거북선 포탄 | **앞의 가장 가까운 라이벌을 자동 추적**(라인 보정) |
| 🏺 고려청자 | 자기 뒤 트랙에 설치, 밟으면 스턴 1.8초 |
| 👑 왕의 위엄 | 강력 부스터 — **순위가 뒤질수록 등장 확률 증가**(러버밴딩) |

- 아이템 사용: `Space` 또는 터치 📦 버튼
- 명중 시 화면 상단 토스트 알림: "○○의 거북선 포탄에 맞았어요! 💥" / "○○에게 신기전 적중! 🎯" / "○○의 고려청자를 밟았어요! 🏺💥"
- 획득 알림: "🏺 고려청자 획득!"

## 5. 트랙 2종

공용: 폭 14유닛 리본 도로, 체커 무늬 출발선, "SUPERSTAR KART" 현수막 아치 + 기둥 2개, 컬러 관중석 3기, 트랙 밖 이탈 시 최고속도 55%.

1. **선셋 비치 서킷** (입문): 넓은 모래사장 + 바다(큰 평면) + 원뿔 산 7기 + **야자수 26그루**(줄기 + 6잎 콘 잎사귀) + 구름
2. **경복궁 서킷** (조선의 법궁): 궁궐 마당 지형, **전각 4기**(2단 석축 월대 + 단청 적색 판옥 + 청록 띠 + 이중 기와 원뿔지붕), **경회루 연못 + 누각**(기둥 4개), 트랙 주변 **기와 담장**, 소나무 20그루(이중 원뿔). 선셋 비치와 다른 코스 레이아웃(15개 커브 포인트).

- 트랙은 차량 선택 화면에서 선택, 로딩/결과 화면 문구에 트랙 이름 반영
- 트랙 전환 시 기존 월드 오브젝트는 그룹으로 모아 통째로 제거 후 재생성(메모리 누수 주의)

## 6. 난이도 선택 (3단계 — 반드시 전부 구현)

차량 선택 화면의 세 번째 카드 그룹에서 선택. 기본값은 보통.

| 난이도 | AI 기본 속도 배율 | 러버밴딩 | AI 아이템 사용 주기 | AI 필살기 발동 | 설명 문구 |
|---|---|---|---|---|---|
| 🐣 쉬움 | ×0.78 | 플레이어에게 강하게 유리 (AI 최대 −18% 감속) | 15~25초 간격 | 안 함 | "처음 달리는 분께 추천" |
| 😎 보통 | ×0.86 | 표준 (±15%) | 9~19초 간격 | 게이지 100% 시 낮은 확률 | "균형 잡힌 기본 레이스" |
| 🔥 어려움 | ×0.94 | 러버밴딩 약화 (AI 앞서도 −5%까지만 감속) | 6~12초 간격, 거북선 포탄 비중 증가 | 게이지 100% 즉시 발동 | "역사 속 최강자들과의 대결" |

- 난이도는 AI `update` 로직에 계수로 적용 (스탯 구조를 바꾸지 말고 최종 타겟 속도·쿨다운에 반영)
- 로딩 화면 UP NEXT 박스와 결과 화면에 선택 난이도를 함께 표기

## 7. 레이스 시스템

- **8인 레이스**(플레이어 + AI 7명, AI는 캐릭터 중 랜덤 중복 없이), 2열 스타트 그리드, **LAP 1/3**
- 카트 5종 (선택 가능 + AI 랜덤): 레이싱 카트("작고 가벼운 기본 경주 카트"), 포뮬러("날렵한 F1 경주차"), 스포츠카("낮고 매끈한 오픈카"), 오프로드 버기("큰 바퀴의 산악 버기"), 클래식 레이서("1950년대 클래식 경주차") — 차종별 실제 3D 형태가 달라야 함(포뮬러는 노즈/앞날개/뒷윙, 버기는 큰 바퀴+롤케이지 등). 카트는 캐릭터 능력치에 곱해지는 보정치(top/acc/hand) 보유.
- **차량 물리**: 가속/최고속(능력치 합성, 부스터 시 ×1.45), 드리프트(드리프트 버튼 + 조향으로 진입, 차체가 안쪽으로 꺾이고 연기 파티클, 0.7초 이상 유지 후 놓으면 **미니 터보**, 1.3초 이상이면 대형 터보), 코스 밖 감속
- **로켓 스타트**: "1" 표시 중 드리프트 입력 → GO 순간 부스터 + "🚀 로켓 스타트!"
- **AI 주행**: 랜덤 위상의 사인 곡선으로 라인 배회, 스탯 기반 속도, **러버밴딩**(난이도 6절 참조), AI가 아이템 획득/사용/필살기 발동
- 순위는 (완주자는 완주시간, 그 외는 lap+t 진행도)로 실시간 정렬
- 파티클: 드리프트 연기(흰색, 카메라 향해 빌보드), 부스터 화염(주황/노랑), 명중 폭발

## 8. HUD (레이스 중)

- 좌상단: 아이템 슬롯(58px, 획득한 유물 이모지 표시) + ⏸ 버튼(일시정지 오버레이: 계속 달리기/처음으로) + 😊 버튼(랜덤 감정 표현 토스트) + 스피드미터 "122 km/h"(speed×3.6 표시) + 필살기 게이지
- 중상단: **실시간 백미러** — 같은 씬을 후방 카메라로 2번 렌더(`renderer.setScissor/setViewport` 사용, 프레임 div에 맞춰 클리핑)
- 우상단: 순위 "2위 / 8"(금색), "LAP 1/3", 타이머 "0:14.06", **원형 미니맵**(트랙 윤곽 + 플레이어 금색/라이벌 분홍 점)
- 하단: 좌측 가상 조이스틱(포인터 캡처), 우측 [⚡필살기][📦아이템][💨드리프트] 원형 버튼
- 상태 알림 토스트(2.2초 유지)

## 9. 조작

- 키보드: `←→`(또는 A/D) 조향, `↑`(오토 액셀 기본) / `↓`(S) 브레이크, `Shift` 드리프트, `Space` 아이템, `E` 필살기
- 모바일: 터치 조이스틱 + 버튼 3개 (pointer 이벤트, touch-action:none)

## 10. 완료 검수 기준 (전부 충족해야 done)

1. `superstar-kart.html` 하나만 존재, 의존성은 Three.js CDN뿐
2. 브라우저 더블클릭으로 실행 → 타이틀에서 7화면 전체가 끊김 없이 동작
3. 트랙/카트/캐릭터/아이템이 전부 3D 메시로 렌더되고 카메라가 부드럽게 추적
4. 트랙 2종(선셋 비치·경복궁)과 난이도 3단계가 실제로 게임플레이를 바꾼다 (환경 메시·AI 속도/아이템 주기로 확인 가능해야 함)
5. 3랩 완주 시 결과 순위표(트랙명·난이도 표기 포함)가 뜨고 재시작 가능
6. 키보드·터치 입력 모두 동작
7. 코드에 정의된 모든 함수가 실제 호출 가능(미정의 참조/콘솔 에러 0)
8. 파일 저장 후 `node --check`(JS 부분 추출) 또는 동등한 방법으로 문법 검증을 직접 수행하고 결과를 보고할 것

작업 방식: 파일을 생성한 뒤 스스로 문법 검증을 돌리고, 발견된 오류를 수정한 후, 위 검수 기준 충족 여부를 체크리스트로 보고해줘.
