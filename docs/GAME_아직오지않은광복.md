# 『아직 오지 않은 광복』 : 1940년 9월, 그들이 걸었던 선택

한국광복군 창설(1940. 9. 17.)을 소재로 한 **웹페이지 기반 역사 추리 시뮬레이션**입니다.
학생은 대한민국 임시정부 한국광복군 총사령부의 **기록병**이 되어, 실제 사료를 읽고 단서를 모아
1940년 창설부터 1945년 광복까지 광복군이 걸어간 선택을 **시대 순서대로** 추리합니다.

기존 React 앱(History Globe)의 Firebase 계정·학급·교사 대시보드 인프라 위에 얹어 만들었습니다.
학생은 **교사가 준 학급코드로 가입**하고, 웹사이트를 껐다가 다시 로그인해도 **자기 계정으로 이어서** 진행합니다.

## 콘텐츠 구조 (약 15~20분)

1. 제1장 · 안개의 도시, 충칭 (1940 여름) — 왜 정규군인가
2. 제2장 · 총사령부 성립, 그날의 선언 (1940. 9. 17.) — 한국광복군 선언문
3. 제3장 · 흩어진 이들을 부르다 (1940~1942) — 여성 대원·조선의용대 합류
4. 제4장 · 세계를 향한 선전포고 (1941. 12. 10.) — 대일 선전 성명서
5. 제5장 · 버마 전선의 목소리 (1943) — 인면전구공작대
6. 제6장 · 국내로 들어갈 준비 (1945 여름) — OSS 국내정진군
7. 제7장 · 아직 오지 않은 광복 (1945. 8. 15.) — 백범일지, 자력 해방의 좌절

콘텐츠·사료는 `src/game/story.ts`, 인물은 `src/game/figures.ts`, 핵심 용어는 `src/game/glossary.ts`.

### 학습 보조·평가 기능
- **단서 수첩(핵심 용어)**: 각 미션 브리핑에서 어려운 낱말을 수준별로 풀어 주는 접이식 용어 설명.
- **오늘의 한 문장(서술형)**: 완료 화면에서 ‘아직 오지 않은 광복’의 의미를 한 문장으로 적어 저장(학생 계정).
- **교사 학습 현황**: 학급 상세에서 학생 행을 펼치면 미션별 정오·시도 횟수·소감을 확인하고, **CSV로 내려받기**.

### ⚠ 사료 검증 안내
원문(발췌)은 국가보훈부·국사편찬위원회 「대한민국 임시정부 자료집」 등에서 널리 인용되는 구절을 옮긴 것이며,
회고록 인용은 판본에 따라 표현이 다를 수 있어 요지 위주입니다. 수업에서 원문을 그대로 제시할 때는
각 사료의 APA 출처·note에 적힌 소장처에서 **정확한 판본·표기를 최종 확인**하세요.

```bash

```

## Firebase 배포 (개인정보 안전)

이 저장소는 **Spark(무료) 요금제 범위(Auth·Firestore·Hosting)** 만 사용합니다.

1. **Firebase 프로젝트 준비**
   - 콘솔에서 프로젝트 생성 → Authentication에서 **이메일/비밀번호** 로그인 사용 설정(교사·학생 공통).
     (교사 Google 로그인을 쓰려면 Google 공급자도 켜고, 콘솔의 Authentication → 설정 → 승인된 도메인에 배포 도메인 추가)
   - Firestore Database 생성(프로덕션 모드).
2. **웹 앱 설정값을 `.env` 에** 채우기 (`.env.example` 복사). 클라이언트 키는 공개되어도 무방하며,
   보안은 전적으로 `firestore.rules` 가 강제합니다. 배포용은 `VITE_USE_EMULATORS=false`.
3. **프로젝트 지정**: `.firebaserc` 의 `default` 를 본인 프로젝트 ID로 바꾸거나 `firebase use <projectId>`.
4. **배포**
   ```bash
   npm run build                                   # dist/ 생성
   firebase deploy --only firestore:rules,firestore:indexes
   firebase deploy --only hosting
   # 또는 한 번에
   npm run deploy
   ```
   `firebase.json` 의 hosting.public 은 **dist** 이며, SPA 리라이트와 Firebase 연결을 허용하는
   보안 헤더(CSP 등)가 설정되어 있습니다.

### 개인정보 보호 설계
- 학생은 이메일 없이 **학급코드 + 번호 + 4~6자리 비밀번호**로 가입합니다. 내부적으로만
  `{학급접두어}-{번호}@student.local` 가상 이메일을 씁니다(학생에게 노출 안 됨).
- 게임 진행(`game_progress`)에는 점수·완료 미션 등 **학습 기록만** 저장하며, 담당 교사와 본인만 접근합니다.
- 이름/실명·연락처 등 민감정보를 수집하지 않습니다(표시 이름은 별명 사용 가능).

## 수업 흐름
1. 교사 로그인 → 학급 개설 → **학급코드** 안내.
2. 학생: 랜딩/`join`에서 학급코드·번호·비밀번호로 가입 → 학생 홈의 『아직 오지 않은 광복』 카드로 시작.
3. 난이도(중/고) 선택 → 시대순 7개 미션 진행(사료 검토 → 추리 → 해설·배지).
4. 교사: 학급 상세 페이지의 **진행 현황**에서 학생별 난이도·완료 미션·점수를 실시간 확인. `미리보기`로 직접 체험.
