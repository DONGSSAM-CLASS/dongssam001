# 동쌤의 뒷담사(史) 영상판 — 세계 최초의 고객 불만 편지

중학교 역사 「Ⅱ. 문명의 발생과 고대 세계의 형성 › 메소포타미아 문명」(교과서 22쪽)과 연결한 29초짜리 모션 그래픽 영상입니다.
교과서에는 "수메르인은 점토판에 쐐기 문자로 … 교역 내용 등을 기록하였다"까지만 나옵니다. 영상은 그 교역 기록 가운데
실제로 남아 있는 **'세계에서 가장 오래된 고객 불만 편지'(에아나시르 점토판)** 를 뒷이야기로 다룹니다.

## 내레이션 대본 (4문장, 약 19초)

1. 약 3,750년 전 메소포타미아의 우르.
2. 구리 상인 에아나시르가 불량 구리를 내밀었어요.
3. 화난 손님 난니는 점토판에 '날 뭘로 보는 거요!'라고 새겨 보냈죠.
4. 세계에서 가장 오래된 고객 불만 편지랍니다.

## 사실 확인 메모

- **시기·장소**: 기원전 1750년경(고바빌로니아 시대), 수메르의 도시 우르. 교과서 지도에도 우르가 표시되어 있습니다.
- **유물**: 점토판, 아카드어 쐐기 문자, 높이 11.6cm × 너비 5.0cm × 두께 2.6cm. 영국박물관 소장, 등록번호 131236.
  (박물관 수장고 등록 기호는 1953,0411.71이며, 상설 전시 중이 아닐 수 있습니다.)
- **발굴**: 레너드 울리가 1920~30년대에 우르를 발굴하면서 에아나시르의 집으로 추정되는 건물(일명 'Old Street 1번지')에서 찾았습니다.
  같은 집에서 품질 불량이나 배송 지연을 따지는 다른 편지도 여러 점 나왔습니다(편지 수는 자료마다 다르게 집계되어 영상에서는 "여러 장"으로만 표현했습니다).
- **내용**: 난니는 에아나시르가 좋은 구리 주괴를 주겠다고 약속하고 질 나쁜 주괴를 내밀었으며, 심부름꾼을 "적지를 지나" 여러 번 빈손으로 돌려보냈다고 항의합니다.
  "살 거면 사고, 아니면 가쇼!"는 편지에 인용된 에아나시르의 말("If you want to take them, take them; if you do not want to take them, go away!")을 옮긴 것이고,
  "날 뭘로 보는 거요?"는 "What do you take me for, that you treat somebody like me with such contempt?"를 줄여 옮긴 것입니다(A. L. Oppenheim 영역).
- **딜문**: 에아나시르는 딜문(오늘날 바레인 일대)을 오가던 구리 상인('딜문 무역상')이었습니다.
- **기록**: 기네스 세계 기록에 '가장 오래된 고객 불만 문서(Oldest written customer complaint)'로 올라 있습니다.
- **주의**: 남아 있는 것은 손님 쪽 편지뿐이라 에아나시르의 해명은 알 수 없습니다. 수업에서 '뒷담화는 한쪽 이야기'라는 토론 거리로 쓸 수 있습니다.

참고: British Museum Collection Online 131236 · A. Leo Oppenheim, *Letters from Mesopotamia* (1967) · Guinness World Records "Oldest written customer complaint" · National Geographic, "Meet Ea-Nasir, a shady ancient merchant—and modern meme".

## 제작 방식

- **그림**: GPT Image 2(Higgsfield 경유, 4K)로 2×2 그리드 2장을 만든 뒤 1920×1080 장면 7장 + 스티커 시트 1장으로 잘랐습니다.
  스티커는 초록 배경을 크로마키로 지워 `public/stickers/*.png`로 만들었습니다.
- **내레이션**: Higgsfield TTS(MiniMax, Hana 음성) → `public/audio/narration.mp3`. 단어별 타이밍은 faster-whisper로 측정해 `src/copy.ts`에 반영했습니다.
- **모션 그래픽**: Remotion 4. 랜섬 노트 제목, 손글씨 라벨(써지는 효과 + 체크), 튀어나오는 스티커, 도장, 말풍선, 찢어진 종이 전환, 별밤 시간 점프로 구성했습니다.
- **글꼴**: Black Han Sans(제목), Nanum Pen Script(손글씨), Noto Sans KR(본문) — 모두 OFL, `@fontsource`로 번들합니다.

## 다시 만들기

```bash
cd dwitdamsa-video
npm install
npm run dev                      # Remotion Studio 미리보기
npm run render                   # 16:9
npm run render:reels             # 9:16
```

문구와 타이밍은 `src/copy.ts`, 장면 배치는 `src/Main.tsx`, 재사용 효과는 `src/parts.tsx`에 있습니다.
크롬 다운로드가 막힌 환경에서는 `--browser-executable=<chrome-headless-shell 경로>`를 붙여 렌더하세요.
