## 프로젝트 개요

저장소 `dongssam-class/dongssam001`의 **`vibe-coding/` 폴더**에 교사 연수용 정적
웹페이지가 있습니다. 코딩 경험이 없는 현직 교사가 60분 안에 웹앱을 만들어
Firebase Hosting에 배포하고 QR로 학생에게 공유하도록 안내하는 워크북입니다.
구현과 브라우저 검증은 끝난 상태이고, 남은 것은 아래 작업들입니다.

**작업 시작 전에 `vibe-coding/CODEX_HANDOFF.md`를 반드시 먼저 읽고 제약 조건을
숙지하세요.**

### 핵심 제약 (어기면 안 됩니다)

- 빌드 도구·번들러·npm 패키지 없음. **CDN만** 사용.
- daisyUI를 Tailwind CDN 스크립트보다 **먼저** 로드. 테마 `cupcake` 고정, 다크모드 토글 만들지 말 것.
- QR은 클라이언트 라이브러리로만 생성. **외부 QR 생성 API 호출 금지.**
- 서버·로그인·수집·분석·광고 스크립트 일절 없음. 상태는 `localStorage`만.
- 스크린샷 이미지 대신 **CSS/SVG 목업**으로 화면을 그릴 것. 이모지 남발 금지(Lucide 아이콘 사용).
- 본문 최소 16px, 명령어 블록 17~18px. 375px에서 가로 스크롤 0px 유지.
- **문체는 존댓말로 통일.** 모든 설명은 "코딩을 처음 하는 50대 선생님이 이해할 수 있는가"를 기준으로.
- **확인되지 않은 수치(요금·통계·수상 내역)를 지어내지 말 것.** 공식 문서 링크로 대체.
- **지시한 요소만 변경하고, 언급하지 않은 부분은 그대로 둘 것.**

> ⚠️ 저장소 **루트의 `firebase.json`과 `public/`은 다른 앱('아고라의 딜레마')이 쓰고
> 있습니다.** 이 사이트는 `vibe-coding/` 하위의 독립 사이트입니다. 반드시
> `cd vibe-coding` 후에 `firebase` 명령을 실행하세요.

## 앞으로 진행할 작업 (우선순위 순)

### 1. 갤러리 7개 + 에크연의 실제 페이지 제목 확인 — **최우선**

제목·설명은 **미검증 초안**입니다. 아래 URL을 각각 열어 실제 페이지 제목을 확인하고,
다르면 `vibe-coding/public/assets/js/app.js`의 `GALLERY` 배열을 수정하세요.

5. https://suneung-textbook.web.app/ — 현재 "교과서 단원별 수능 기출 탐색기"

### 2. QR 실제 동작 확인

STEP 7의 QR 위젯에 `https://example.web.app` 같은 주소를 넣고 다음을 확인하세요.

- qrcodejs(CDN)가 실제로 QR을 그리는지 — **휴대폰 카메라로 직접 찍어** 주소가 맞게 열리는지
- "전면 송출하기" 모달에서 큰 QR이 뜨고 ESC·바깥 클릭으로 닫히는지
- "PNG로 저장"이 파일을 내려받는지
- 갤러리 카드의 "QR 띄우기"가 각 앱 주소로 정상 동작하는지

문제가 있으면 `app.js`의 `drawQr()` / `openQrModal()`을 고치되, **외부 QR 생성 API는
절대 쓰지 마세요.**

### 3. 실제 CDN 환경에서 전체 재검증

최초 검증은 CDN이 차단된 환경에서 저장소에 있던 동일 라이브러리로 대체해 진행했습니다.
실제 CDN(daisyUI 4.12.24 / Tailwind / Pretendard / Lucide / qrcodejs)이 로드되는
환경에서 다시 확인해 주세요.

- 1280px·375px 양쪽에서 **콘솔 에러 0건**
- **가로 스크롤 0px**
- cupcake 테마 색상이 의도대로 나오는지 (파스텔 민트·코럴·크림)
- Lucide 아이콘이 전부 렌더링되는지 (약 165개)
- Pretendard 글꼴이 적용되는지
- `Ctrl+P` 인쇄 미리보기에서 내비·서브·복사 버튼이 숨고 실습 코스만 유인물처럼 나오는지

### 4. 명령어 재검증

`CODEX_HANDOFF.md` 6장의 표에 있는 설치·로그인·배포 명령어를 공식 문서로 다시 확인하고,
바뀐 것이 있으면 본문과 `app.js`의 `TOOLS` 객체를 함께 수정하세요.
**확실하지 않은 옵션은 쓰지 말고 공식 문서 링크로 대체하세요. 요금 수치는 적지 마세요.**

### 5. Firebase Hosting 배포

```bash
cd vibe-coding
firebase login
firebase init hosting   # 기존 프로젝트 선택 / public 디렉터리는 public /
                        # SPA는 N / GitHub 자동배포는 N / index.html 덮어쓰기는 반드시 N
firebase deploy
```

배포 후 발급된 `https://<프로젝트>.web.app` 주소로 접속해 위 3번 항목을 한 번 더
확인하고, 주소를 보고해 주세요.
