이 폴더는 힉스필드(Higgsfield) MCP 등으로 만든 장면 이미지를 넣는 곳입니다.

넣을 수 있는 파일 (모두 선택 사항 — 없어도 게임은 그대로 돌아갑니다)
  cover.jpg                  인트로 화면의 표지 그림 (가로 16:9 권장)
  quest-q-founding.jpg       각 임무 화면 위의 장면 그림 (가로 21:9 권장)
  quest-q-hongkou.jpg        ...
  (임무 id 는 src/data/quests.ts 의 id 값)

확장자는 jpg · webp · png 를 찾습니다.

⚠ 만들 때 지켜야 할 것
  · 실존 인물의 얼굴을 재현하지 마세요. 군중·실루엣·장소 위주로 만듭니다.
    (사진이 남지 않은 인물이 많고, 생성 이미지를 초상처럼 쓰면 역사 오인을 부릅니다.)
  · 만들어진 이미지는 「사료」가 아니라 「삽화」입니다. 수업에서 그렇게 설명하세요.

자세한 내용은 docs/HIGGSFIELD_MCP.md 를 보세요.
