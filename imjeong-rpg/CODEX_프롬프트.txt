너는 중학교 역사 교사(동쌤, 김동은 선생님)가 수업에 쓸 웹게임을 이어서 개발한다.

■ 프로젝트
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
『임시정부 1919-1945』 — 대한민국 임시정부(1919~1945)의 외교·군사 활동을
사료에 근거해 체험하는 아이소메트릭(쿼터뷰) 3D 역사 RPG 웹게임.
화면 구성은 천하제일상 『거상』 온라인을 참고했다.
플레이 대상은 **중학교 1학년**이다.

기술: React 19 + TypeScript + three.js + zustand + Vite + Vitest.
외부 3D 모델·텍스처·폰트 파일을 쓰지 않고 전부 코드로 만든다.

현재 상태: 7개 도시, 실존 인물 34명, 사료가 붙은 퀘스트 23개를 갖춘
플레이 가능한 완성본. 타입 검사·테스트 73개·프로덕션 빌드 모두 통과.

■ 시작하기 전에 반드시 할 일
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. `README.md` 를 읽어 전체 구조를 파악한다.
2. `docs/CODEX_HANDOFF.md` 를 읽는다. 남은 일이 우선순위대로 있다.
3. `docs/HISTORY_SOURCES.md` 를 읽는다. 역사 서술의 원칙과 주의점이 있다.
4. `npm install && npm run check` 로 현재 상태가 통과하는지 확인한다.
   (npm install 이 edgesOut 오류로 실패하면 .npmrc 에 legacy-peer-deps=true 를 넣는다)
5. `npm run dev` 후 아래 세 화면을 눈으로 확인한다.
   - http://localhost:5183/            게임
   - http://localhost:5183/?lineup     인물 34명 3D 검수
   - http://localhost:5183/?portraits  인물 34명 2D 초상 검수

■ 절대 어기면 안 되는 규칙 (역사 수업 자료다)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. 모든 퀘스트에 사료가 1개 이상, 각 사료에 APA 출처가 있어야 한다.
2. 일자·판본에 이설이 있는 사건에는 반드시 `caveat` 로 그 사실을 밝힌다.
   "이렇게 알려져 있다"와 "이것이 사실이다"를 섞지 않는다.
   (예: 수립일 4월 11일·13일, 대일 선전 성명서 12월 9일·10일,
        장제스의 윤봉길 관련 발언은 출처가 확정되지 않았다)
3. 인물의 공과를 미화하지 않는다.
   이승만의 탄핵, 이광수의 변절, 김원봉의 엇갈린 평가를 사실대로 쓴다.
4. **실존 인물의 얼굴을 재현하지 않는다.**
   사진으로 확인되는 옷·머리·안경·수염만 `src/data/figures.ts` 의
   `appearance` 에 옮기고, 이목구비는 양식화한다.
   차림을 바꾸거나 인물을 추가하면 `appearance.note` 에 근거를 반드시 적는다.
5. 폭력 장면을 플레이어가 조작하게 하지 않는다.
   의열 투쟁은 "왜 그 선택이었고 무엇을 바꾸었나"로 다룬다.
6. 개인정보를 수집하지 않는다. 로그인이나 서버 저장을 추가하지 않는다.
   진행 기록은 학생 브라우저의 localStorage 에만 둔다.
7. 중학교 1학년이 읽을 수 있는 한국어를 쓴다.
   어려운 낱말은 `src/data/glossary.ts` 에 풀이를 추가한다.
8. 맵(`src/data/maps.ts`)은 직접 고치지 말고 `scripts/gen-maps.py` 를 고쳐
   `python3 scripts/gen-maps.py` 로 다시 생성한다.

■ 코드 규칙
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- 게임 규칙은 `src/engine/` 에 **순수 함수**로 넣는다. three.js·React 를 넣지 않는다.
  새 규칙에는 반드시 테스트를 함께 쓴다.
- 3D 렌더링은 `src/three/WorldRenderer.ts` 가 React 밖에서 자체 루프로 돌린다.
  매 프레임 React 를 다시 그리지 않는다.
- 인물의 차림은 `src/data/figures.ts` 의 `appearance` 한 군데에서만 정한다.
  3D(`src/three/character.ts`)와 2D 초상(`src/ui/portrait.ts`)이 이걸 함께 읽는다.
- 외부 3D 모델·텍스처 파일을 추가하지 않는다. 필요하면 캔버스로 그린다
  (`src/three/textures.ts` 방식을 따른다).
- 재질은 여러 물체가 공유하므로 텍스처 반복은 재질이 아니라
  지오메트리 UV(`src/three/geom.ts` 의 scaleUV)로 조절한다.
- 주석은 **왜 그렇게 했는지**를 한국어로 적는다. 무엇을 하는지는 코드가 말한다.
- 커밋 전에 `npm run check` 를 돌려 타입·테스트·빌드가 모두 통과하는지 확인한다.

■ 할 일
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
`docs/CODEX_HANDOFF.md` 4절 「남은 일」을 위에서부터 하나씩 처리한다.
큰 것만 옮기면 다음과 같다.

[콘텐츠]
- 사료 원문을 국사편찬위원회 한국사데이터베이스에서 대조해 표기를 확정하고
  각 사료의 note 를 갱신
- 퀘스트 추가: 워싱턴회의(1921~22) 한국대표단, 신규식의 광둥 호법정부 교섭,
  창사 남목청 사건(1938), 1944년 제5차 개헌, 미주 대한인국민회의 재정 지원
- 파리·워싱턴 맵의 퀘스트 보강 (지금은 각 1~2개뿐이라 방문 유인이 약하다)
- 동지 영입에 쓸모 주기 (예: 김규식이 있어야 열리는 외교 선택지)

[게임성]
- 일제 감시(heat)가 85를 넘으면 청사 습격·이동 강제 사건이 일어나게 하기
  (heatLevel() 은 이미 있다. 지금은 수치만 오르고 아무 일도 없다)
- 막이 바뀔 때 시대 전환 연출
- 23개를 모두 풀었을 때의 완료 화면 (「오늘의 한 문장」 쓰기)

[비주얼]
- 옷의 무늬 — 여성 한복의 색동 끝동, 군복 계급장 같은 작은 무늬
- 실내 장면 (`'+'` 실내 바닥 타일은 이미 준비되어 있다)
- 밤·비 조명 프리셋과 창문 불빛(litWindows) 켜기
- 힉스필드 MCP 로 삽화 24장 만들기 (`npm run assets:higgsfield` → docs/HIGGSFIELD_MCP.md)

[접근성]
- 키보드 조작 (방향키 걷기, Tab 으로 NPC 순회, Enter 로 대화)
- 저사양 자동 전환 (setMaterialQuality('low') 경로는 있으나 자동 감지가 없다)
- 모바일 터치 (핀치 줌, 큰 터치 영역)
