## 2. 절대 깨뜨리면 안 되는 규칙

이것을 어기면 **수업 자료로 쓸 수 없게 됩니다.** 테스트가 대부분을 막지만,
사람이 지켜야 하는 것도 있습니다.

1. **모든 퀘스트에 사료(`sources`)가 1개 이상, 각 사료에 APA 출처(`citationApa`)가 있어야 합니다.**
   → `src/data/content.test.ts` 가 검사합니다.
2. **`choice.historical` 과 정답이 일치해야 합니다.** 정답인 선택지만 `historical: true`.
3. **일자·판본에 이설이 있는 사건에는 `caveat` 를 답니다.**
   지금 필수로 검사하는 것: `q-founding`, `q-declaration-war`, `q-hongkou`, `q-cairo`, `q-mandate-dispute`.
4. **실존 인물의 얼굴을 3D 로 재현하지 않습니다.** 옷차림과 색으로만 구분합니다.
   (`src/three/character.ts` 상단 주석)
5. **폭력 장면을 조작하게 하지 않습니다.** 의열 투쟁은 판단과 결과로 다룹니다.
6. **개인정보를 수집하지 않습니다.** 로그인·서버 저장을 추가하지 마세요.
   추가해야 한다면 학교 개인정보 처리 절차를 먼저 밟아야 합니다.
7. **중학교 1학년이 읽을 수 있는 문장**을 씁니다. `middle` 은 쉬운 말, `high` 는 깊은 설명.
   같은 사건·같은 사료를 다루되 설명의 깊이만 다릅니다.

## 4. 남은 일 (우선순위 순)

### 4-1. 콘텐츠

      한국사데이터베이스에서 원문과 대조해 표기를 확정하고, `note` 를 갱신하세요.
- [ ] **퀘스트 추가.** 다루지 못한 것: 워싱턴회의(1921~22) 한국대표단,
      신규식의 광둥 호법정부 교섭, 창사 남목청 사건(1938), 1944년 제5차 개헌,
      미주 대한인국민회의 재정 지원.

## 5. 구조에서 알아 둘 점

### 3D 와 React 를 분리했습니다

`WorldRenderer` 는 React 밖에서 자체 루프를 돌립니다. 매 프레임 React 를 다시 그리면
저사양 기기에서 프레임이 떨어지기 때문입니다. React 는 HUD·대화창만 그립니다.
둘을 잇는 곳은 `src/GameScreen.tsx` 한 곳뿐입니다.

### 규칙은 전부 순수 함수입니다

`src/engine/` 에는 three.js 나 React 가 들어가지 않습니다. 그래서 테스트가 쉽고 빠릅니다.
**새 규칙은 반드시 `engine/` 에 순수 함수로 넣고 테스트를 함께 쓰세요.**

### 건물 발자국은 자동으로 통행을 막습니다

맵 지형 문자열에는 **땅만** 그립니다. 건물과 부피 있는 소품의 발자국은
`buildWorldGrid()` 가 자동으로 통행 불가로 바꿉니다. 지형과 건물이 어긋나
캐릭터가 벽을 뚫는 사고를 원천적으로 막기 위한 구조입니다.

### 재질은 공유합니다

`materials.ts` 의 재질은 여러 건물이 함께 씁니다(드로우콜 절약).
그래서 **텍스처 반복 횟수를 재질에 넣을 수 없습니다.** 대신 `geom.ts` 의 `scaleUV()` 로
지오메트리의 UV 를 늘려 건물마다 알맞은 밀도로 무늬가 반복되게 합니다.
