# Codex 에 그대로 붙여 넣을 프롬프트

아래 내용을 Codex(또는 다른 코딩 에이전트) 대화창에 그대로 붙여 넣으세요.

---

```
너는 중학교 역사 교사가 수업에 쓸 웹게임을 이어서 개발한다.

## 프로젝트
저장소의 `imjeong-rpg/` 폴더. 『임시정부 1919-1945』라는 아이소메트릭 3D 역사 RPG다.
대한민국 임시정부(1919~1945)의 외교·군사 활동을 사료에 근거해 체험하게 만든다.
천하제일상 『거상』 온라인의 화면 구성을 참고했다.
플레이 대상은 **중학교 1학년**이다.

## 먼저 할 일
1. `imjeong-rpg/README.md` 를 읽어 전체 구조를 파악한다.
2. `imjeong-rpg/docs/CODEX_HANDOFF.md` 를 읽는다. 남은 일 목록이 우선순위대로 있다.
3. `imjeong-rpg/docs/HISTORY_SOURCES.md` 를 읽는다. 역사 서술의 원칙과 주의점이 있다.
4. `cd imjeong-rpg && npm install && npm run check` 로 현재 상태가 통과하는지 확인한다.

## 절대 어기면 안 되는 규칙
1. 모든 퀘스트에 사료가 1개 이상, 각 사료에 APA 출처가 있어야 한다.
2. 일자·판본에 이설이 있는 사건에는 반드시 `caveat` 로 그 사실을 밝힌다.
   ("이렇게 알려져 있다"와 "이것이 사실이다"를 섞지 않는다)
3. 인물의 공과를 미화하지 않는다. 이승만의 탄핵, 이광수의 변절 같은 것을 사실대로 쓴다.
4. 실존 인물의 얼굴을 3D 로 재현하지 않는다. 옷차림과 색으로만 구분한다.
5. 폭력 장면을 플레이어가 조작하게 하지 않는다.
6. 개인정보를 수집하지 않는다. 로그인이나 서버 저장을 추가하지 않는다.
7. 중학교 1학년이 읽을 수 있는 한국어를 쓴다. 어려운 낱말은
   `src/data/glossary.ts` 에 풀이를 추가한다.
8. 맵(`src/data/maps.ts`)은 직접 고치지 말고 `scripts/gen-maps.py` 를 고쳐 다시 생성한다.

## 코드 규칙
- 게임 규칙은 `src/engine/` 에 **순수 함수**로 넣는다. three.js·React 를 넣지 않는다.
  새 규칙에는 반드시 테스트를 함께 쓴다.
- 3D 렌더링은 `src/three/WorldRenderer.ts` 가 React 밖에서 자체 루프로 돌린다.
  매 프레임 React 를 다시 그리지 않는다.
- 외부 3D 모델·텍스처 파일을 추가하지 않는다. 필요한 것은 코드로 만든다.
  (`src/three/textures.ts` 의 캔버스 생성 방식을 따른다)
- 주석은 **왜 그렇게 했는지**를 한국어로 적는다. 무엇을 하는지는 코드가 말한다.
- 커밋 전에 `npm run check` 를 돌려 타입·테스트·빌드가 모두 통과하는지 확인한다.
```
